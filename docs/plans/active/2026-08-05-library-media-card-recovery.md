# 图片与视频素材库卡片恢复

> Status: active-plan
> Owner: frontend
> Last verified: 2026-08-05

## 背景与根因

线上图片库与视频库的媒体卡片被压缩为很薄的条目。生产页检查确认：当素材没有可直接加载的
缩略图时，卡片的备用预览区域虽然已渲染，但父容器只保留了 6px 内边距，导致 4:3 或 16:9
预览被裁掉；卡片只剩标题和状态。

同时，`asset-workspace-adapter.ts` 的 `previewUrlForAsset` 只接受 HTTP(S) 地址。历史图片的
`original_ref` 使用受控存储引用时没有转换为已有的后端媒体代理地址，因而不显示真实缩略图。
这不是视频质量门禁或线上数据被删除。

## 具体改法

1. 将图片/视频媒体卡改为纵向流式布局，并让外层预览框占满明确的卡片宽度、不可伸缩，再固定
   对应比例（图片 4:3、视频 16:9），且不在预览框或卡片本身使用会影响尺寸计算的溢出裁切。
   卡片圆角改由不参与尺寸计算的裁切路径保持。这样浏览器能按确定宽度计算预览高度，真实缩略图
   和无缩略图时的备用预览都占据同样的可见区域；不改变列表分页、标题、理解状态或选择行为。
2. 将已保存素材的受控存储引用统一通过已有 `/v1/video/media` 代理转换为浏览器可读地址；HTTP(S)
   地址继续直连。只使用该素材已保存的引用，不引入任意 URL 或新的数据写入。
3. 增加回归测试：历史内部图片引用生成代理预览地址；图片、视频没有缩略图时仍输出具有固定比例
   的备用预览样式；已有缩略图路径保持不变。

## 涉及文件

- `MultiMix-Frontend/app/assets/lib/asset-workspace-adapter.ts`：受控存储引用的预览地址映射。
- `MultiMix-Frontend/app/globals.css`：图片/视频媒体卡的比例与备用预览布局。
- `MultiMix-Frontend/app/assets/__tests__/asset-workspace-adapter.test.ts`：历史图片引用回归。
- `MultiMix-Frontend/app/assets/__tests__/agent-ui-copy.test.ts`：媒体卡样式契约回归。

## 风险与取舍

- 只恢复展示，不回填、移动或修改用户素材和数据库记录。
- 媒体仍走已有后端代理与访问控制；不把内部存储地址直接暴露给浏览器。
- 无缩略图时显示明确的备用预览，而不是伪造真实图片或视频封面。
- 从栅格卡片改为纵向流式卡片，只影响卡片内部上下排列，不改变素材库的外层列数或筛选、点击行为。

## 验证方式

- 运行前端适配器与素材库样式相关 Vitest 测试。
- 运行类型检查或针对性静态检查。
- 在已登录的线上页面复核图片库与视频库：真实缩略图能显示；没有缩略图的卡片仍为正常比例、可读且可点击。

## 实施记录

- 已让图片、视频媒体卡的外层预览框分别固定为 4:3 和 16:9；没有缩略图时，备用预览不再因
  栅格尺寸计算而被裁成细条。
- 已让素材库把受控存储引用（例如历史图片的 `supabase://...`）转换为已有媒体代理地址；HTTP(S)、
  `data:` 和 `blob:` 地址保持原样。
- 已新增历史内部图片引用回归测试与媒体卡比例样式契约测试；定向 Vitest 87 项、TypeScript
  类型检查和 ESLint 均通过。
- 线上首次验收发现，仅给预览框设置比例仍会被卡片自身的栅格自动行裁掉；将补充卡片纵向流式
  布局，确保预览框的比例高度参与卡片高度计算，再重新验收。
- 第二次线上验收确认纵向流式布局已生效，但预览框的宽度仍是由拉伸间接得到，比例高度没有解析。
  将补充 `width: 100%` 和不可伸缩约束，使比例计算有明确基准后重新验收。
- 第三次线上验收确认预览框已得到正确的比例高度，但它自身的 `overflow: hidden` 让上层网格计算
  时忽略了该高度。内部缩略图和卡片外层已负责裁切，故移除预览框的这条重复裁切规则后重新验收。
- 第四次线上验收确认卡片外层仍有同样的 `overflow: hidden`，网格因此只按标题行排高。将以圆角
  裁切路径替代该溢出裁切，使预览高度完整参与网格行高计算后重新验收。
- 已发布到 `multimix-frontend` 正式环境（部署 `dpl_B5AUv8DjBuTKNNGXVKjvST1XMq1n`）。线上实测
  图片卡约 242px 高、预览区约 181px；视频卡约 197px 高、预览区约 136px，均恢复正常比例。
