# 桌面 UI 远端合并与生产部署计划

> Status: active-plan
> Owner: frontend
> Last verified: 2026-09-17

## 背景与根因

本地 `main` 已完成并验证桌面工作台、项目列表和资源库视觉整改，但推送前发现远端 `main` 已新增 19 个提交，包含创作档案、创作入口定位、视频进度与依赖修复。正常合并在 5 个共享 UI 文件产生内容冲突。根因是两组改动同时修改了首页入口、资源库组件、全局样式和对应权威设计，并非功能实现本身失败。

冲突解决后的定向回归另外暴露出一处跨分支测试夹具不一致：远端新增的“视频修改失败、上一稳定版本仍可用”用例从空产物继承了 `空状态 / 等待指令`，同时仍按旧版完整标题断言；本地已确认设计则要求产物卡显示“明确产物类型 + 版本 + 状态”。实际生产逻辑无需回退，测试夹具需要改为真实稳定产物状态，并按 `视频工程 · v1` 验证上一稳定产物仍存在。

完整文档检查还发现远端提交引用了三个未进入当前后端仓库的历史计划文件。相关产品规则已经完整写在当前前端规格中，因此移除失效的实施记录链接，避免把不存在的文件冒充验收依据；不改变产品合同本身。

隔离浏览器验收显示失败恢复动作已由远端统一视频进度卡收敛为紧凑的“重试”按钮，但本地截图用例仍查找旧时间线按钮“重新执行此步骤”。页面实际保留了且只保留一个恢复动作，符合当前进度卡规范；E2E 需要改为验证紧凑进度卡中的单一“重试”动作，避免把旧组件文案当作视觉合同。

## 涉及文件与关键位置

- `app/assets/components/conversation-start.tsx`：保留远端创作入口定位与本地主页层级、项目列表呈现。
- `app/assets/components/library-workshop.tsx`：保留远端视频/创作能力与本地资源库无结果、分页和详情行为。
- `app/globals.css`：合并创作档案/进度样式与桌面 UI 整改样式，不回退已确认播放器和资源库视觉契约。
- `docs/MULTIMIX_WORKSPACE_DESIGN.md`：同时记录远端产品定位、创作档案规则和本地资源库交互规范。
- `docs/specs/ui/prototypes/current/screens/start.html`：保留远端入口文案，维持本地已确认的桌面布局与项目列表状态表达。
- `app/assets/lib/asset-workspace-shared.ts`：核对空产物与正式产物身份规则，保持现有生产判定不变。
- `app/assets/__tests__/video-progress-integration.test.tsx`：把场景夹具改为真实稳定版本，并按当前产物身份规范验收。
- `docs/specs/ui/product-positioning.md`、`docs/specs/ui/video-confirmation-execution-card.md`：移除不存在的历史实施记录引用，保留当前产品与交互合同。
- `e2e/display-area.spec.ts`：按统一视频进度卡的当前动作文案验证失败恢复，同时继续禁止展示区重复操作。

## 具体改法

1. 逐个读取冲突两侧与关联测试，不使用整文件覆盖。
2. 以远端新增产品能力为基础，重新叠加本轮已确认的视觉与交互规则。
3. 修正跨分支测试夹具：明确稳定产物的完成状态和版本，按当前“类型 + 版本”规范验证失败修改后旧版本仍存在。
4. 保留双方新增测试；冲突解决后先运行定向测试，再运行完整前端测试、类型、ESLint、构建、文档和契约检查。
5. 使用隔离 E2E 复测桌面首页、项目状态、生成中、失败恢复、资源库与详情，不打开剪辑器。
6. 合并提交通过工作区提交锁后推送远端 `main`，等待 Vercel `lywgood96-1172s-projects / multimix-frontend` 生产部署并在 `https://multimix-frontend.vercel.app` 验证。

## 风险与取舍

- 禁止选择 `ours` 或 `theirs` 整体覆盖，避免丢失任一侧能力。
- 远端新增创作档案和入口定位属于功能能力，优先保证其行为与测试；本地已确认视觉规范作为不可回退约束叠加。
- 本轮仍不验收手机端和剪辑器；相关远端文件只接受自动合并结果，不主动扩展修改范围。
- 若合并后完整检查或生产验证失败，停止推送或按实际生产状态回滚，不以修改测试期望掩盖问题。

## 验证方式

- 定向测试：入口文案、创作档案、资源库交互与视频进度相关测试。
- 完整检查：`npm test -- --run`、`npm run typecheck`、`npm run lint`、`npm run build`、`npm run check:agents`、`npm audit --omit=dev --audit-level=high`。
- 隔离 E2E：普通项目、生成中、失败恢复、桌面起始页、资源库跨类型详情。
- 生产验收：目标项目身份、部署提交、首页与资源库页面、控制台错误、性能与截图。
