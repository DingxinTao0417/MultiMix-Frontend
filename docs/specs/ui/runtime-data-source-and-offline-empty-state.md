# 运行时真实数据源与离线空状态

> Status: current
> Owner: frontend
> Last verified: 2026-07-12

## 1. 目标

MultiMix 工作台运行时只展示真实后端返回的数据。前端内置演示数据不得参与页面初始化、接口失败降级或真实空列表展示，避免用户把样例内容误认为自己的对话和资产。

mock 数据只允许作为自动化测试 fixture 存在，不进入生产运行时依赖图。

## 2. 数据源规则

### 2.1 后端已配置

当 `NEXT_PUBLIC_API_BASE_URL` 非空时：

1. 页面首次进入显示加载骨架。
2. 获取有效登录 token 后请求真实后端。
3. 请求成功且有数据：展示真实对话和真实资产。
4. 请求成功但列表为空：展示真实空状态。
5. 请求失败：展示加载失败状态和“重新加载”，不展示样例数据。

### 2.2 后端未配置

当 `NEXT_PUBLIC_API_BASE_URL` 为空时：

- 不加载演示对话或演示资产。
- 工作台显示“未连接后端”。
- 提供配置说明，不提供会产生假持久化预期的创建、保存、上传和生成操作。
- 登录壳可以继续使用 local 模式进入工作台，但工作台必须明确处于不可创作的离线空状态。

### 2.3 禁止行为

- 禁止用 `mockAssetWorkspaceData` 初始化生产页面状态。
- 禁止接口超时、401、403 或 5xx 后回退演示数据。
- 禁止真实列表为空时补入样例行。
- 禁止本地 mock 修订、保存或恢复版本伪装成真实成功。

## 3. 用户可见状态

### 3.1 加载中

```text
对话列表
┌────────────────────┐
│ ▒▒▒▒▒▒▒▒      ▒▒  │
│ ▒▒▒▒▒▒        ▒▒  │
│ ▒▒▒▒▒▒▒▒▒     ▒▒  │
└────────────────────┘
正在加载你的对话…
```

加载中不显示数量，避免先显示 mock 数量再跳变。

### 3.2 真实空列表

```text
对话列表                         0

还没有对话
从“新建对话”开始第一次创作
```

只有后端成功返回空数组时才显示。

### 3.3 加载失败

```text
对话加载失败
没有展示本地样例，避免与真实数据混淆。

[重新加载]
```

401/403 继续走现有登录失效流程；连接失败或 5xx 留在工作台错误态。

### 3.4 未配置后端

```text
未连接后端
请配置 NEXT_PUBLIC_API_BASE_URL 后重启前端。

创作、上传和保存暂不可用
```

## 4. 代码边界

### 4.1 生产运行时

- `AssetsWorkspaceClient` 初始数据为空，不调用同步 mock snapshot。
- adapter 负责真实后端请求，不再以 `createMockAssetWorkspaceAdapter(mockAssetWorkspaceData)` 作为生产单例。
- 页面状态显式区分：`idle | loading | ready | empty | error | unconfigured`。
- 对话列表数量只在 `ready/empty` 后展示。
- 新建对话、资源库和产物展示都使用同一运行时数据状态，不各自回退 mock。

### 4.2 测试 fixture

- 将测试所需样例移动到测试目录或改名为明确的 fixture 模块。
- 测试通过依赖注入或测试 helper 传入 fixture。
- 生产组件、生产 adapter 和生产入口不得 import fixture。
- 静态 HTML 原型继续作为设计参考，不属于应用运行时数据。

## 5. 兼容策略

- 保留现有 `AssetWorkspaceAdapter` 类型边界，减少 UI 组件改动面。
- 删除 adapter 中本地 mock 的保存、修订、恢复和生成成功分支。
- 需要离线组件测试时，通过测试 adapter 实现接口，不在生产 adapter 中保留双模式分支。
- `.env.example` 明确说明 API 为空代表“未配置”，不再代表可用 demo 工作台。

## 6. 验证案例

### 6.1 对话列表

- [ ] 初次加载时只出现骨架，不闪现演示对话或错误数量。
- [ ] 后端返回 4 条时始终显示 4 条真实对话。
- [ ] 后端返回空数组时显示数量 0 和真实空状态。
- [ ] 后端请求失败时显示错误与“重新加载”，列表中没有演示标题。
- [ ] API 未配置时显示“未连接后端”，不显示 22 条样例。

### 6.2 资源库

- [ ] 资产库、文案库、图片库和视频库首次加载不闪现 mock 卡片。
- [ ] 真实后端返回空数组时保持空态。
- [ ] 任一库加载失败时不回退对应 mock 行。

### 6.3 操作门禁

- [ ] `unconfigured` 状态下不能创建假对话、假修订或假保存结果。
- [ ] `error` 状态下“重新加载”重试真实接口。
- [ ] token 失效仍触发现有重新登录流程。

### 6.4 依赖边界

- [ ] 生产入口和生产 adapter 不包含 `asset-workspace-mock-data` import。
- [ ] mock fixture 只被测试文件或测试 helper 引用。
- [ ] 构建、类型检查和现有产品契约测试通过。

## 7. 非目标

- 不删除 `docs/specs/ui/prototypes/` 下的静态设计原型。
- 不创建或保留本地 SQLite 运行库。
- 不改变后端对话、资产、视频工程或 MG 的数据结构。
- 不在本次工作中重新设计登录方式。
