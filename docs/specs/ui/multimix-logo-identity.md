## 1. 目标与使用场景

MultiMix 的品牌标识用于对外展示产品，主要覆盖：

- 导出视频的片尾、片头或画面角标；
- 对外发布图片的署名与水印；
- 产品头像、favicon、社交媒体头像等小尺寸场景；
- 产品页面和宣传材料中的品牌署名。

首要验收标准是：在复杂视频画面和不同明暗背景上仍然清楚，小尺寸时能够辨认，且不会抢夺内容主体。

## 2. 已确认的设计方向

### 2.1 核心概念

标志由两个视觉动作组成：

- 一笔式、圆角的 `M` 表达 MultiMix 对图片、视频和文档等多种素材的混合与组织；
- 向右的开放箭头表达从素材进入编导、生成并产出成片的过程。

整体气质选择“流动剪辑”，强调现代、清晰和推进感。标志不使用写实镜头、胶片格、魔法棒、星芒或复杂 AI 粒子，避免与通用剪辑器和生成式 AI 图标趋同。

### 2.2 颜色

用户确认采用黑白极简方案：

- 主黑：`#151515`；
- 反白：`#FFFFFF`；
- 不使用紫青渐变、科技蓝或其他品牌色作为 LOGO 主版本；
- 阴影、半透明底板和描边只属于具体画面的应用层，不烘焙进 LOGO 文件。

### 2.3 文字组合

标准字固定写作 `MultiMix`，保持两个 `M` 大写。默认对外水印使用“图标 + MultiMix”的横版组合，同时提供纯图标版供头像、favicon 和极小角标使用。

### 2.4 实心角标补充版（用户 2026-10-11 确认）

用户在 9 个方向比对后确认 `E + H`：主标方向不变，另外新增**实心角标版**作为补充：圆角底板承担对比度，内部为反白的 `M + 箭头`。

- 定位是补充版，不是主标。线性版仍是默认对外标识。
- 适用范围限定：`≤48px` 的小尺寸场景，以及明暗不定或细节繁杂、线性版容易被吞掉的视频画面角标。
- 使用 badge 时不再另加阴影或半透明底板，底板本身即对比来源。
- 该版本是第 3 节“不封闭成徽章”的**唯一例外**，依据为用户当次确认；不得据此把徽章形式推广到主标或横版。

标准字使用简洁的几何无衬线风格，字重接近 Semibold/Bold。最终 SVG 中应转换为轮廓路径，不依赖观看设备是否安装对应字体。

## 3. 标志结构

- 图标采用等粗线条、圆形端点和圆角连接；
- `M` 保持开放、连续，不封闭成徽章或实心方块（2.4 的 badge 版为唯一例外）；
- 向右箭头与 `M` 保持独立负空间，小尺寸下仍能看出“推进”而不是第二个字母；
- 横版组合中，图标与标准字垂直居中；
- 不增加 slogan，不增加 `.ai`、`Video Agent` 等后缀。

### 3.1 纯图标与 badge 的构图基准（2026-10-11 修正）

纯图标必须在 192 画布内视觉居中，并四边留出安全区。原始 mark 的可见边界为 `x 18→190`、`y 28.63→156`，右侧仅剩 `2px`，方形裁切会切掉箭头尖端且重心右倾；因此生成时对 mark 整体施加仅用于构图的变换：

- `scale(0.814)` + `translate(11.35, 20.86)`，长边占 `140/192`，形状、比例、颜色与 `stroke-width` 全部不变；
- 修正后实测重心 `(96.06, 96.06)`，四边最小安全区 `25.88px`；
- badge 底板为 `x/y=16`、`160×160`、`rx=38`，内部 mark 在上述居中变换后再 `scale(0.62)`（约占底板 54%，经 24px 复杂画面实测确定）；
- 该构图由 `scripts/__tests__/multimix-logo-assets.test.mjs` 的像素级断言守住（四边安全区 `≥15px`、重心偏移 `≤1px`），不得只改实现而放宽断言。

## 4. 版本与交付文件

成品保存到 `MultiMix-Frontend/public/brand/`，包括：

1. `multimix-logo-horizontal-black.svg`：透明底的浅色背景主标；
2. `multimix-logo-horizontal-white.svg`：透明的深色背景反白主标；
3. `multimix-logo-icon-black.svg`：黑色纯图标；
4. `multimix-logo-icon-white.svg`：白色纯图标；
4b. `multimix-logo-badge-black.svg`：黑底板 + 反白 mark 的实心角标；
4c. `multimix-logo-badge-white.svg`：白底板 + 黑 mark 的实心角标；
5. 对应透明 PNG，横版以高分辨率宽图输出，纯图标与 badge 以 `1024×1024` 输出（badge 底板不透明、底板外透明）；
6. `multimix-logo-preview.png`：同时展示明暗背景、横版、纯图标和视频角标应用的预览页。
7. `brand-kit-manifest.json` 与 `README.md`：机器可读清单和面向使用者的简版说明；
8. `multimix-brand-kit.zip`：固定地址 `/brand/multimix-brand-kit.zip` 的完整品牌包。

SVG 是长期主文件；PNG 用于不方便直接消费 SVG 的视频、图片和第三方平台。全部资产由 `scripts/generate-multimix-logo-assets.mjs` 统一生成，`multimix-brand-kit.zip` 按 `brand-kit-manifest.json` 的 `files` 自动重建；禁止手工编辑 `public/brand/` 下的产物。

## 5. 使用规则

- 浅色背景使用黑色版，深色背景使用白色版；
- 复杂画面优先使用白色版，并在视频或图片合成层增加轻微阴影或中性半透明底板；
- 底板不是 LOGO 的组成部分，不写入透明主文件；
- 横版标识四周安全区不小于图标高度的 `25%`；
- 1080p 视频角标建议宽度为 `140–180 px`，距画面边缘 `24–32 px`；
- 纯图标不小于 `24 px`，横版标识不小于 `96 px` 宽；
- 不拉伸、不旋转、不改变图标与标准字比例，不在同一版本内混用黑白两色；
- badge 版用于 `≤48px` 场景与复杂画面角标，浅色画面用白底板、深色画面用黑底板；使用 badge 时不再叠加阴影或半透明底板；
- badge 不替代主标：产品页面、宣传材料和常规署名仍用线性横版或纯图标。

## 6. 风险与取舍

- 黑白方案跨画面适配最稳，但品牌色记忆弱于彩色渐变；通过独特的连续 `M + 箭头` 结构补足识别度。
- 开放式线条在极小尺寸可能丢失细节，因此保留纯图标版，并以 `24 px` 作为最低可用尺寸；更小或更繁杂的场景改用 badge 版。
- 居中修正使纯图标内的 mark 占比由约 `90%` 降至约 `73%`，与旧版并排时观感略小；以安全区合规和不被裁切为优先。已发布的旧物料不会自动更新，但仍可继续使用。
- badge 引入封闭底板，与线性主标气质不同，且会在画面上占一块实色；因此严格限定为补充版，使用范围写入第 5 节。
- 标准字转轮廓能保证跨设备一致，但后续修改字形需要重新导出源文件；SVG 文件中应保留清晰命名和版本说明。

## 7. 验证方式

- 检查所有 SVG 能独立打开且没有外部字体、图片或滤镜依赖；
- 检查所有 PNG 具有真实透明通道，没有白底或黑底残留；
- 分别在浅色、深色和复杂画面上预览黑白版本；
- 在 `24 px` 纯图标和 `96 px` 横版尺寸检查识别度；
- 核对标准字始终为 `MultiMix`，没有大小写或拼写漂移；
- 运行 `npm --prefix MultiMix-Frontend run docs:check`，确认新规范的状态头和文档入口符合要求。

## 8. 产品内导出

- 图片产物的“下载”菜单提供“下载原图”和“下载品牌展示版”；
- 视频产物与视频编辑器的“导出视频”菜单提供“原始成片”和“品牌展示版”；
- 品牌展示版按画面短边相对 1080 px 等比例使用 `160 px` 宽、右下各 `28 px` 的白色横版标识；
- 品牌展示版是独立输出，不修改原图片、视频工程、时间轴或已有原始成片；
- 未选择品牌展示版时仍按原始版导出，不对历史项目静默加水印。

## 8.1 产品内品牌标记（用户 2026-10-12 确认）

- 工作台页面头部的项目切换器、导航面板、登录页、重置密码页与服务条款/隐私政策页的品牌标记，统一改为 2.4 节的**黑色 badge**：`#151515` 圆角底板 + 反白 `M + 前进箭头`。这些位置都在 `≤48px`，按 2.4 节使用 badge，底板即对比来源，不再加阴影、半透明底板或渐变圆底。
- 产品代码通过共享组件 `app/components/brand-mark.tsx` 绘制，字形与 `public/brand/multimix-logo-badge-black.svg` 一致；不得在页面内另行内联简化字形或恢复紫青渐变底。
- 7 个当前原型的品牌标记同步为该 badge。
- 管理后台（产品指标页）头部与访问受限卡片同样使用该组件。
- 站点图标使用同一 badge（用户 2026-10-12 要求补齐）：`app/icon.svg`（矢量，viewBox 裁到底板）、`app/favicon.ico`（16/32/48）、`app/apple-icon.png`（180×180，`#151515` 满版底，由 iOS 自行切圆角）。均由 `public/brand/multimix-logo-badge-black.*` 生成，不另画字形。

## 9. 已否决的设计方向（2026-10-11 评审记录）

用户要求重做并比对了 9 个版本后确认 `E + H`。以下记录保留否决理由，避免后续重复提案或重走同一条路。每条结论都来自 24 / 48 / 96px 与明暗、复杂渐变画面的实际渲染对比，不是口头判断。

| 代号 | 方向 | 结论 | 否决或采纳理由 |
| --- | --- | --- | --- |
| E0 | 一笔 `M + 箭头`，原始导出 | 有缺陷 | 概念正确但构图越界：右侧安全区仅 `2px`，方形裁切切掉箭头，重心右倾。按 3.1 修正后采纳。 |
| E | 同概念，居中修正 | **采纳为主标** | 保留已确认概念与既有品牌资产，形状零改动，仅修构图；小尺寸可辨度维持。 |
| H | 实心角标 | **采纳为补充版** | `24px` 复杂画面下唯一稳定可辨的版本，且自带对比度。限定用途见 2.4 与第 5 节。 |
| C | 对话气泡 + 播放三角 | 否决 | 是唯一在图形上讲清“用对话改视频”的方向，识别度也达标；但与通用评论、视频消息图标高度撞型，品牌独占性弱于独特字形。 |
| A / A2 | 多条素材线汇入播放三角 | 否决 | 概念最贴“多素材 → 一条成片”，但 v1 汇合点与三角连成一团，`96px` 即糊；v2 留间隙后读成快进符号，且与 `Mix` 的字面含义断开。 |
| B | 五根混音推子构成 `M` 峰谷 | 否决 | 实际读成音频均衡器，把产品指向音乐/音频而非视频；`24px` 完全看不出字母。 |
| D | 三个递增镜头方块 + 播放三角 | 否决 | 叙事清楚，但方块互相重叠、线条过密，`48px` 起并成一块。 |
| G | 两笔交错表示上下穿插 | 否决 | 图形最独特，但读成 `XX` / `W` 而非 `M`，且不含任何“视频”信号，需要大量品牌投入才能教会用户。 |

评审得出的通用结论，后续提新方向时直接复用：

- 三项必须同时成立才值得取代现版：**字母可识别**、**24px 可辨**、**不撞通用图标库**。9 个方向中没有一个同时胜过现版概念，因此换概念的收益低于风险。
- 线条型标志在小尺寸的失效点是“笔画间距”而非笔画粗细；元素数量超过 2 组就会在 `48px` 并块（见 A、D）。
- 把抽象概念直译成图形（推子 = Mix、交错 = Mix）容易被读成所属行业的通用符号，反而偏离产品品类。

## 10. 当前范围外

- 不修改播放器 UI；
- 不制作动态 LOGO、声音标识、品牌色系统或完整品牌手册；
- 不同步修改商业计划和两份融资 PPT。
