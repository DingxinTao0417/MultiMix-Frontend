# 分镜卡片与换素材窗口设计

> Status: current
> Owner: frontend
> Last verified: 2026-07-12

## 目标

统一视频方案、成片预览、分镜浏览和换素材操作的视觉语义，让用户快速判断“这一镜讲什么、当前画面是什么、是否需要处理素材”，同时把匹配算法和渲染细节收进详情层。

本设计沿用当前可点击原型 `docs/specs/ui/prototypes/current/screens/workspace-video.html` 的素材选择器视觉骨架，并以当前前端真实组件为落地对象。

## 1. 视频比例一致性

- `product.ratio` 是展示区的比例真相源。
- 视频方案、加载占位、轻量分镜预览和真实视频播放器必须使用同一比例。
- `16:9` 使用横屏画布，`9:16` 使用竖屏画布；加载前后不得改变外框比例。
- 分镜素材选择器中的缩略图展示“放入当前工程后的裁切预览”，跟随工程横竖比例。

## 2. 分镜卡片

每张卡片只保留：

- 分镜序号与时间段
- 当前素材缩略图
- 分镜标题或画面意图
- 一行口播或字幕摘要
- 必要的异常状态
- `换素材` 操作

展示规则：

- 正常素材命中不显示额外状态。
- 没有可用素材且需要用户处理时显示 `待补素材`。
- 公共素材可以在详情层标注为 `公共素材`，分镜列表不使用 `兜底素材` 文案。
- MG 只显示用户能理解的简短表达标签，例如 `数字强化`；渲染阶段、模板技术名和失败原因放详情层。MG 失败可以作为需要处理的异常状态显示。
- 当前分镜保留明确选中态；`换素材` 在 hover、键盘 focus 和选中态可见。

## 3. 换素材窗口

窗口沿用当前原型的居中弹窗、顶部标题、三列候选网格和上传入口，但不原样复制旧文案。

### 信息结构

1. 标题：`为分镜 #N 换素材`
2. 说明：`替换后只更新当前分镜，不影响其他分镜。`
3. `AI 推荐 · 和这段最匹配`
4. `素材库 · 已理解的素材`
5. 没有合适素材时的上传入口

### 候选规则

- AI 推荐和素材库默认只展示用户已保存的图片/视频素材。
- 后端推荐顺序继续以分镜 `asset_reference` 语义匹配结果为准。
- 公共素材只允许在 `asset_reference.status=no_asset_hit` 后出现，不能排在已保存素材前面。
- 匹配理由使用简短用户语言，例如 `匹配“施工过程”和“工人操作”`；不显示置信度、候选 ID 或内部字段。

### 选择与确认

- 点击候选先进入选中态，不立即提交替换。
- 弹窗底部显示 `取消` 和 `确认替换`。
- 未选择候选时禁用 `确认替换`。
- 确认后仅对当前分镜调用已有 `replace_material` 重合成接口。
- Escape、遮罩点击和关闭按钮均关闭窗口，不提交替换。

## 4. 信息分层

分镜列表负责回答“这一镜是什么、需不需要处理”。以下信息放到详情层：

- 素材来源类型
- 匹配原因和其他候选
- MG 模板、选择原因与渲染状态
- 内部任务、置信度和调试信息

## 5. 验收案例

- 16:9 视频工程在方案标题、轻量预览、加载占位和播放器中均为横屏。
- 9:16 视频工程在上述位置均为竖屏。
- 已匹配素材的分镜卡不显示素材状态标签。
- 无可用素材的分镜卡显示 `待补素材`，页面不显示 `兜底素材`。
- 点击 `换素材` 后打开与当前原型同一视觉语言的居中弹窗。
- 点击候选仅选中；点击 `确认替换` 后才提交当前分镜替换。
- 素材选择器显示 AI 推荐、已理解素材库和上传入口；推荐不可用时隐藏推荐区但保留素材库。

## 6. 浏览态快捷操作与生成状态

### 视频生成进度点

- `视频生成进度` 标题后的状态点必须直接表达整条执行状态。
- 生成中为黄色，全部完成为绿色，任一步失败为红色。
- 状态点自身写入对应背景色，不能只依赖祖先文字颜色继承。

### 分步状态图标

- 每条生成步骤左侧的成功与失败图标固定使用 18px 圆形容器，不改变步骤行布局。
- 成功态使用绿色粗对勾、浅绿色背景和绿色边框；不得通过缩放或降低透明度弱化状态。
- 失败态使用红色粗叉号、浅红色背景和红色边框。
- 对勾与叉号统一使用 12px 图标和 3px 描边，确保在普通缩放比例下仍能快速识别。
- 等待态与运行态保持现有表达，不随本次调整改变。

### 浏览态导出

- `video_project_ready` 的视频工程在展示区顶部始终显示 `导出视频`。
- 导出入口与 `详情 / 编辑 / 保存` 同层，不要求用户先进入编辑器。
- 浏览态保留一个不可见的编辑器导出桥接实例；点击导出只触发导出，不切换到编辑视图。
- 导出准备、进行、成功和失败继续使用真实编辑器消息更新按钮状态。

### 浏览态换素材

- 分镜卡 `换素材` 直接在浏览态打开本设计第 3 节的居中素材选择窗口。
- 打开、取消和确认期间均保持成片预览与分镜列表，不切换到编辑器。
- 确认后只调用当前分镜的 `replace_material` 重合成接口。
- timeline 已有手工修改时，继续使用现有覆盖确认门；用户拒绝后不提交。
- 重合成进行中显示真实任务状态，完成后刷新当前对话中的视频产物。
