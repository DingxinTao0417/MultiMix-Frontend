## 1. 背景与目标

V3 视觉重设计的目标：

1. **易用**：非技术背景的本地商家（门窗/家装等）白天在店里用电脑操作，不需要学习成本
2. **清晰**：商家始终知道 AI 在做什么、用了他的哪些素材、交付到了哪一步
3. **AI 原生**：AI 的存在感来自「可视化的真实过程」（理解、拆解、引用、生成），不是装饰性科幻光效

设计性格：温暖亮底的专业工具 + 有生命感的智能体。参照气质：Claude × v0 × Arc。

## 2. 设计原则（不可打破）

1. **产物是视觉重心**：真实产物出现后，右侧展示区让结果成为页面焦点；尚无产物时保持单栏对话
2. **AI 渐变纪律**：品牌渐变 `--ai-grad` 用于待确认卡描边、真实运行阶段、生成动效、AI 头像、发送按钮、理解徽章圆点、对话输入坞描边和起始页低饱和 aurora。普通交互、普通选中态和已完成状态使用中性色或 `--accent` 单色；依赖流式事件的动效仅在有真实数据时出现
3. **素材状态必须可见**：已理解 / 处理中 / 被引用 N 次，在素材卡、引用芯片、来源块中始终可感知
4. **确认卡是最重要的交互**：待确认态是全界面唯一渐变描边的卡片；已确认态收成中性 hairline 摘要，并保留绿色状态戳
5. **过程即品牌**：视频进度卡只可视化服务端真实公开阶段，禁止虚构步骤、耗时或百分比

## 3. 设计 Token

```css
:root{
  --bg:#FAF9F7; --surface:#FFFFFF; --surface-2:#F5F3EF;
  --ink:#201F1E; --ink-2:#6E6A64; --ink-3:#9B968E;
  --line:#EAE7E1; --line-2:#DDD9D1;
  --ai-a:#7C5CFF; --ai-b:#00A88E;
  --ai-grad:linear-gradient(120deg,#7C5CFF,#00A88E);
  --ai-soft:linear-gradient(120deg,rgba(124,92,255,.09),rgba(0,168,142,.09));
  --accent:#5B45E0; --accent-soft:#EEEAFF;
  --warn:#9A6A00; --warn-soft:#FFF3D9;
  --ok:#0E8A6B;
  --radius:16px; --radius-sm:12px;
  --shadow-card:0 2px 6px rgba(32,31,30,.05),0 16px 40px rgba(32,31,30,.07);
}
```

- 字体栈：`"Segoe UI","Microsoft YaHei UI","PingFang SC","Noto Sans SC",sans-serif`
- 基准字号 14px；正文行高 1.6–1.8；标题 1.3–1.4
- 间距 4px 网格；边框 1px hairline；卡片圆角 16px、控件 12px、按钮胶囊 999px
- 渐变描边实现（双层背景技法）：`border:1px solid transparent; background:linear-gradient(var(--surface),var(--surface)) padding-box,var(--ai-grad) border-box`

## 4. 布局骨架

有真实产物的桌面工作台使用三栏 grid：`264px 侧边栏 | clamp(480px,52%,720px) 对话流 | minmax(420px,1fr) 产物区`，中间保留 `6px` 可拖拽分隔条；`1180px` 及以下按当前窄屏规则收起侧栏。尚无产物时对话单栏居中。工作台占满视口，用户拖拽后保持所选宽度，键盘调整和 ARIA 使用相同边界。页面结构以[当前工作台设计](../../MULTIMIX_WORKSPACE_DESIGN.md#3-页面结构)为准。

### 4.1 桌面视觉层级

- 项目名只出现在导航与对话头部；对话产物卡和展示区头部显示“产物类型 · 版本”，状态使用相邻状态标记表达。
- 产物类型只消费 `artifact_category`、约定 `content_type` 和确定性 `mode` 兜底，不按标题或正文猜测。
- 对话产物卡在消息列内使用 `min(100%, 560px)`；图片结果使用显式全宽网格轨道并顶部对齐。
- 操作高度分为 30px 紧凑产物工具栏、36px 普通操作、40px 主要操作；可读元信息不得小于 12px。
- 对话时间线有真实可重试步骤时，它拥有唯一恢复动作；展示区只说明失败范围。生成中和失败时隐藏保存、编辑与导出。
- 图片库的“内容类型”和“处理状态”是两个有名称、可组合的筛选组。
- 新建项目页不预选开始方式；帮助说明靠近能力提示，卡片仅在点击后显示选中态。

## 5. 核心组件规范

### 5.1 侧边栏（264px）

- 品牌：26px 渐变圆 mark（白色 M 线稿）+ MultiMix 字标 14.5px/650
- 「+ 新建项目」：`--ink` 深色实底胶囊按钮（38px 高）——非生成动作不用渐变
- 最近项目优先展示，资产/文案/图片/视频四个资源入口位于项目区下方；展开态资源入口使用 `2 × 2` 轻量卡片。项目搜索覆盖完整项目集合，具体数量和窄屏导航规则见[当前工作台设计](../../MULTIMIX_WORKSPACE_DESIGN.md#3-页面结构)。
- 最近项目行只常驻显示项目名；有行动价值的状态以同行纯文字显示，选中态使用中性浅背景和字重。
- **★ AI 后台状态胶囊**（新组件，列表与用户区之间）：渐变描边小卡，标题行「AI 正在后台工作」+ 呼吸圆点，正文 11px 说明当前后台任务（如“正在理解「施工过程记录 #1」，完成后可直接在对话中引用”）。无后台任务时隐藏整个胶囊
- 用户区：头像圆 + 名称 + 邮箱

### 5.2 对话流（中栏）

- 顶栏 56px：项目标题 15px/650；仅有项目资源时显示紧凑的「资料 · N」入口，窄屏位置按[当前工作台设计](../../MULTIMIX_WORKSPACE_DESIGN.md#50-新建视频项目首入口)处理。
- 用户气泡：`--surface-2` 底、18px 圆角（右下 6px）、无边框；下挂素材引用芯片（34px 高，28px 缩略图 + 名称）
- 助手消息：26px 渐变圆头像（白 sparkle）+ 正文直接排在底上（无气泡）
- **确认卡两态**：
  - 待确认：渐变描边卡，头部标题 +「待确认」徽章（`--warn-soft` 底 + 渐变呼吸点）；字段两列（label 64px 右对齐灰字 / value 墨字，行内微缩略图 22px）；底部按钮行：渐变胶囊主按钮「确认，开始生成」+ hairline 次按钮「调整方向」
  - 已确认：卡片收缩为 2–3 行摘要字段，使用 `--line` 中性 hairline 与白底，右上角绿色戳「✓ 已确认」（`--ok`），无按钮、无渐变描边
- **视频进度卡**：白色 hairline 卡片，详情默认收起；展开后只展示服务端已经发生的公开阶段。运行阶段可以使用渐变呼吸圆与轻量 shimmer，完成阶段使用中性或成功状态。用户界面不显示步骤序号、总步骤数、逐步耗时或内部模型名；具体状态与恢复动作以[视频任务进度卡](video-confirmation-execution-card.md)和[当前工作台设计](../../MULTIMIX_WORKSPACE_DESIGN.md#51-agent-任务确认与执行反馈)为准。
- 建议芯片：白底 hairline 胶囊，hover `--accent-soft`
- 输入坞：渐变描边输入卡（生成中/对话进行时），占位「随时打断或补充，AI 会接着改…」；回形针 + 渐变圆发送按钮

### 5.3 产物区（右栏）

- 面板头：产物名 + 状态徽章（「生成中」活徽章 / 完成后隐藏）+ 元信息行（`文案 · v1 · 来源已标注`）。窄产物列固定为“标题/状态、操作”两行，宽列才回到同一行；标题保留完整文本提示，操作不得把标题压到无法辨认
- **生成态**（已有真实产物及状态时）：
  - 面板背景两团呼吸极光（radial-gradient，透明度 ≤.08，5s alternate 缓动）
  - 产物卡渐变描边；只有真实流式出稿数据时才显示打字光标、字数及当前引用高亮，不以估计值伪装实时生成
- **完成态**（渐变退场）：极光消失、卡片退为 hairline 边框、光标移除；视频来源摘要默认收起，用户展开后才查看素材与引用说明。
- **顶部操作组（统一规则）**：操作始终放在产物区 header，不设置底部操作栏；窄列放在标题下方，宽列放在右侧。这里是紧凑工具栏的明确例外，统一使用 30px 高、`padding: 0 13px`、`gap: 7px`、`border-radius: 999px` 的胶囊按钮；页面主操作和普通表单按钮继续使用舒适点击高度。主操作（复制全文 / 下载 / 编辑 / 完成编辑）使用 `--ink` 深色实底和白字；次操作（详情 / 保存 / 导出）使用 `--surface` 白底、`--line-2` 描边和 `--ink-2` 文字。hover 只做 1px 上浮、阴影和文字加深，禁用态不位移。不同产物可改变按钮文案和显示条件，但不得改变这套主次视觉语义，也不得为视频工程把按钮单独压缩到 26px。
- **展示区滚动边界（统一规则）**：不改变现有产物容器层级；所有实际承担纵向滚动的展示面统一标记为 `stage-scroll-surface`。公共规则把滚动面宽度扩展为 `calc(100% + 24px)`、用 `margin-right: -24px` 抵消产物区右侧 inset，并补回至少 24px 内侧 padding；长文案继续用内容 gutter 保持正文最大宽度和横向位置。滚动面的现有父级不得裁掉这 24px 扩展。每条产物渲染路径只能有一个滚动 owner：视频工程浏览态由 `video-browse` 承担，不能再由外层普通视频 preview 重复承担。无论文案、图片、数字人、普通视频、视频工程浏览态还是后续新增产物，只要在展示区产生纵向滚动，滚动条都必须贴住展示区最右边。禁止按 `.copy`、`.video` 等产物类型分别追加 margin 补丁。

### 5.4 素材可视化元素（跨界面复用）

- 缩略图容器 `.phbox`：`--surface-2` 衬底、9px 圆角、hairline 描边（真实产品中为图片，demo 中为渐变占位）
- 理解徽章「活的胶囊」：白底 hairline 胶囊 + 8px 渐变呼吸圆点 + 「已理解」；处理中用 `--warn` 圆点闪烁
- 被引用计数：`--ink-3` 小字或角标，凡素材出现处都带

### 5.5 视频产物：预览态 ⇄ 编辑态（复用现有内嵌编辑器，不自研剪辑组件）

现状：`product-workspace.tsx` 已将视频产物展示区实现为 `/editor?asset=…&embed=1` 的 OpenCut iframe（含 ready 握手与导出 postMessage 协议）。本设计**保留该编辑器作为唯一剪辑实现**，只在其外加一层很薄的预览壳：

- **预览态（默认）**：视频生成完成后，产物区显示按工程实际比例呈现的预览播放器和分镜摘要卡列表；素材来源摘要默认收起，完整引用关系放在详情。先让用户看到当前结果，修改优先走对话（「第 2 段字卡换成保修年限」）。
- **编辑态（点「编辑」原地切换，形态=胶片条）**：embed 模式的呈现层按「胶片条 + 分镜属性卡」重构（已选定，demo `docs/specs/ui/prototypes/current/screens/workspace-video.html` 为交互基准），不显示多轨时间轴：
  - **胶片轨**：单条，片段按时长比例分宽，标注序号/时长/兜底；点选与预览联动；选中片段两侧出现裁剪把手（拖动裁剪，单段 2–15 秒），「分割/删除」就地出现，无常驻工具栏、无标尺
  - **分镜属性卡**（选中即显示）：画面（当前素材 + 来源标注 + 换素材 → 素材选择器，AI 推荐排序）；配音（文本框直接改台词，字幕实时跟随，「重新配音」局部重合成）；MG 字卡（开关 + 文案，overlay 不占轨道，遵守 `mg_decision` 权威）
  - **成片属性行**：配乐（整条视频一个 BGM，chip 选择；有配音时整条保持固定低音量，不做动态闪避）
  - 底部：撤销 + 覆盖提示 + 总时长徽章；说明行「字幕会自动跟随配音文本 · 需要分轨调整？全屏打开 ↗」
- **全屏 `/editor` 保留**：完整多轨时间轴，承接分轨调整等专业需求，入口只在编辑态说明行；`docs/specs/ui/prototypes/current/screens/editor.html` 为其 V3 换肤视觉参考（换肤单独排期）。
- **两层数据边界（必须实现，且精确到操作）**：属性卡内的修改（换素材=`asset_reference`、配音文本=配音稿、MG=`mg_decision`、配乐）全部作用于分镜/成片语义层，可局部重合成，**AI 重排不覆盖**；胶片上的裁剪/分割作用于渲染层，**AI 重排前必须弹确认「会覆盖你的手工剪辑」**。界面提示语区分两者（「仅裁剪/分割会被覆盖；素材/配音/字卡修改不受影响」）。
- **明确不做**：多轨时间轴不进展示区；配音/字幕/动效不以轨道形式出现在内嵌编辑态。
- 交互细则：展开型切换必须保证新内容立即可见（原地替换或自动滚动到位）。

### 5.6 图片库 / 新建视频项目起始页

以[当前原型](prototypes/current/)为界面基准；早期 C 系探索稿只用于追溯视觉选择：

- 图片库：状态胶囊（已解析=渐变点胶囊 / 待处理=warn 点）压在缩略图右上角；选中卡渐变描边；居中模态详情里的「AI 理解」分区使用 `--ai-soft` 底与活徽章。
- 起始页：低饱和 aurora 背景（透明度 .05–.09）+ 40px/750 大标题 + 渐变描边输入卡 + 渐变圆发送按钮；对话框始终先于开始方式卡出现，是第一操作入口。
- 输入卡下方用一行轻量胶囊说明系统会自动组合 `我的素材 / AI 生成镜头 / 公开素材 / 图形动画 / 口播优化 / 配音与音乐`。这行不接受选择，不暴露 Provider 或渲染器名称。
- `你想怎么开始？`使用三张 88px 左右的背景图卡：`从想法开始`（说出目标，一起确定内容和画面）/ `用素材创作`（上传照片、人物、资料或参考片，制作新作品）/ `修改现有视频`（上传原片，说明要保留和调整的部分）。不放图标；文字位于深色渐变遮罩上；点击只填充输入框。桌面三列，窄屏两列且第三张跨整行，移动端单列。输入框保留一条示例，不再叠加第二组同义示例卡。
- 其下方只在有已审核且获首页公开使用授权的真实作品时展示`看看能做出什么`：成片封面、入口类型、用户提供内容与最终成果先于过程。点击后才打开可控播放与关键过程详情，修改类仅在原片也获授权时展示前后对比。零合格案例时整区隐藏，不用内部 QA 视频或假占位；当前原型的结构示意须明确标注非真实案例。
- UGC 仅作为跨人物、物品、过程和故事的风格选择存在于后续编导结果中，不成为起始页必选分类。混合使用真实素材、生成镜头、公开素材和图形动画时，仍从同一对话框发起。
- 三张入口按开始制作所依赖的输入区分：新片可从想法或素材开始；参考片用于另做新作品时选`用素材创作`，保留现有原片并调整时选`修改现有视频`。人物口型、参考片复刻和活动大屏等具体需求仍通过对话描述；卡片不代表稳定交付承诺。内容目的、表达风格和逐镜制作方式继续由后续对话及编导决策，不把五层改成逐级选择器。
- 新建项目页不显示仅依据部分素材类型推断的「素材已就绪」横条；未来如有统一可用性汇总，再按[当前工作台设计](../../MULTIMIX_WORKSPACE_DESIGN.md#50-新建视频项目首入口)评估该入口。

## 6. 动效规范

| 名称 | 用途 | 参数 |
|---|---|---|
| breathe | 渐变呼吸点/运行步图标 | scale 1→0.8 + opacity，2.2s ease 循环（运行步 1.6s） |
| sweep | shimmer 进度条 | translateX -55%→55%，1.8s ease 循环 |
| aur | 产物区极光 | opacity .65→1，5s ease-in-out alternate |
| blink-c | 打字光标 | opacity step-end，1s 循环 |
| blink | 待处理状态点 | opacity 1→.35，1.4s 循环 |

必须支持 `prefers-reduced-motion: reduce`：全部动画降级为静态（呼吸点定格、shimmer 换成静态渐变条、极光定格低透明度）。

## 7. 可用性与无障碍

- 正文对比度 ≥ 4.5:1（`--ink`/`--ink-2` 在 `--bg`/`--surface` 上已满足）；`--ink-3` 只用于辅助信息
- 主按钮高度 ≥ 36px，点击区不小于 40×40
- 渐变上的白字仅用于按钮短文案（字重 ≥600）
