## 1. 背景与目标

现状 UI（`shadcn-prototype-*` 灰白原型风）缺乏层次、签名色与产品个性。重设计目标：

1. **易用**：非技术背景的本地商家（门窗/家装等）白天在店里用电脑操作，不需要学习成本
2. **清晰**：商家始终知道 AI 在做什么、用了他的哪些素材、交付到了哪一步
3. **AI 原生**：AI 的存在感来自「可视化的真实过程」（理解、拆解、引用、生成），不是装饰性科幻光效

设计性格：温暖亮底的专业工具 + 有生命感的智能体。参照气质：Claude × v0 × Arc。

## 2. 设计原则（不可打破）

1. **产物比对话更重要**：产物区（右栏）是视觉重心；生成时它是全界面唯一「活着」的区域
2. **AI 渐变纪律**：品牌渐变 `--ai-grad` 只出现在「AI 正在参与」的时刻——确认卡描边、Agent 时间线运行步、生成极光、打字光标、实时引用亮框、AI 头像、发送按钮、理解徽章圆点、对话输入坞描边（对 AI 说话的入口）、起始页低饱和 aurora。普通交互（导航、次按钮、标签、筛选）一律用中性色或 `--accent` 单色
3. **素材状态必须可见**：已理解 / 处理中 / 被引用 N 次，在素材卡、引用芯片、来源块中始终可感知
4. **确认卡是最重要的交互**：全界面唯一渐变描边的卡片；有「待确认」（完整字段+双按钮）和「已确认」（紧凑三行+绿色戳）两态
5. **过程即品牌**：Agent 执行时间线可视化的必须是真实发生的步骤与耗时，禁止假进度

## 3. 设计 Token

```css
:root{
  --bg:#FAF9F7; --surface:#FFFFFF; --surface-2:#F5F3EF;
  --ink:#201F1E; --ink-2:#6E6A64; --ink-3:#9B968E;
  --line:#EAE7E1; --line-2:#DDD9D1;
  --ai-a:#7C5CFF; --ai-b:#00A88E;
  --ai-grad:linear-gradient(120deg,#7C5CFF,#00A88E);
  --ai-soft:linear-gradient(120deg,rgba(124,92,255,.09),rgba(0,168,142,.09));
  --accent:#5B45E0; --accent-soft:#EEEAFF;
  --warn:#9A6A00; --warn-soft:#FFF3D9;
  --ok:#0E8A6B;
  --radius:16px; --radius-sm:12px;
  --shadow-card:0 2px 6px rgba(32,31,30,.05),0 16px 40px rgba(32,31,30,.07);
}
```

- 字体栈：`"Segoe UI","Microsoft YaHei UI","PingFang SC","Noto Sans SC",sans-serif`
- 基准字号 14px；正文行高 1.6–1.8；标题 1.3–1.4
- 间距 4px 网格；边框 1px hairline；卡片圆角 16px、控件 12px、按钮胶囊 999px
- 渐变描边实现（双层背景技法）：`border:1px solid transparent; background:linear-gradient(var(--surface),var(--surface)) padding-box,var(--ai-grad) border-box`

## 4. 布局骨架

三栏 grid：`264px 侧边栏 | minmax(0,1fr) 对话流 | 448px 产物区`，最低兼容 1280 宽；100vh 外框，各栏内部滚动。现有组件结构不变（`assets-workspace-client.tsx` 主壳 + 受控子组件），只改样式层与新增两个展示组件。

## 5. 核心组件规范

### 5.1 侧边栏（264px）

- 品牌：26px 渐变圆 mark（白色 M 线稿）+ MultiMix 字标 14.5px/650
- 「+ 新建对话」：`--ink` 深色实底胶囊按钮（38px 高）——非生成动作不用渐变
- 搜索框、导航（资产库/文案库/图片库/视频库，34px 行高，选中态 `--accent-soft` 底 + `--accent` 字）
- 对话列表：选中项同上；日期右对齐 11px `--ink-3`
- **★ AI 后台状态胶囊**（新组件，列表与用户区之间）：渐变描边小卡，标题行「AI 正在后台工作」+ 呼吸圆点，正文 11px 说明当前后台任务（如“正在理解「施工过程记录 #1」，完成后可直接在对话中引用”）。无后台任务时隐藏整个胶囊
- 用户区：头像圆 + 名称 + 邮箱

### 5.2 对话流（中栏）

- 顶栏 56px：对话标题 15px/650 + 右侧活徽章「已引用 N 张素材」（白底胶囊 + 渐变呼吸点）
- 用户气泡：`--surface-2` 底、18px 圆角（右下 6px）、无边框；下挂素材引用芯片（34px 高，28px 缩略图 + 名称）
- 助手消息：26px 渐变圆头像（白 sparkle）+ 正文直接排在底上（无气泡）
- **确认卡两态**：
  - 待确认：渐变描边卡，头部标题 +「待确认」徽章（`--warn-soft` 底 + 渐变呼吸点）；字段两列（label 64px 右对齐灰字 / value 墨字，行内微缩略图 22px）；底部按钮行：渐变胶囊主按钮「确认，开始生成」+ hairline 次按钮「调整方向」
  - 已确认：同卡收缩为 2–3 行摘要字段，右上角绿色戳「✓ 已确认」（`--ok`），无按钮
- **★ Agent 执行时间线**（新组件，确认后出现）：白卡 hairline；头部「MultiMix 正在执行 · 第 x 步 / 共 n 步」+ 呼吸点；步骤行三列（图标 / 文案 / 耗时）：
  - 完成步：绿色对勾圆（`rgba(14,138,107,.1)` 底）+ 墨字 + 实际耗时
  - 运行步：渐变呼吸圆 + 加粗文案（含正在引用的素材名）+ 行下 3px 渐变 shimmer 条
  - 等待步：空心圆 + 灰字 + 「—」
  - 步骤文案面向商家（「已理解 4 张素材」「正在写第 3 段」），不暴露内部模型/工具名（遵守 CLAUDE.md 文案约定）
- 建议芯片：白底 hairline 胶囊，hover `--accent-soft`
- 输入坞：渐变描边输入卡（生成中/对话进行时），占位「随时打断或补充，AI 会接着改…」；回形针 + 渐变圆发送按钮

### 5.3 产物区（右栏 448px）

- 面板头：产物名 + 状态徽章（「生成中」活徽章 / 完成后隐藏）+ 元信息行（`文案 · v1 · 来源已标注`）
- **生成态**（AI 参与时刻，渐变全开）：
  - 面板背景两团呼吸极光（radial-gradient，透明度 ≤.08，5s alternate 缓动）
  - 产物卡渐变描边；正文最后一行尾部 2px 打字光标闪烁；下方「正在写第 x 段 · 已写 a / 约 b 字」
  - 来源引用块（`--ai-soft` 底）：此刻正被引用的素材缩略图渐变亮框，其余常规；注明「来源实时引用中」
- **完成态**（渐变退场）：极光消失、卡片退为 hairline 边框、光标移除；来源块列出「基于 N 张已解析素材生成 + 被引用次数」
- **顶部操作组（统一规则）**：操作始终放在产物区 header 右侧，不设置底部操作栏；统一使用 30px 高、`padding: 0 13px`、`gap: 7px`、`border-radius: 999px` 的胶囊按钮。主操作（复制全文 / 下载 / 编辑 / 完成编辑）使用 `--ink` 深色实底和白字；次操作（详情 / 保存 / 导出）使用 `--surface` 白底、`--line-2` 描边和 `--ink-2` 文字。hover 只做 1px 上浮、阴影和文字加深，禁用态不位移。不同产物可改变按钮文案和显示条件，但不得改变这套主次视觉语义，也不得为视频工程把按钮单独压缩到 26px。
- **展示区滚动边界（统一规则）**：不改变现有产物容器层级；所有实际承担纵向滚动的展示面统一标记为 `stage-scroll-surface`。公共规则把滚动面宽度扩展为 `calc(100% + 24px)`、用 `margin-right: -24px` 抵消产物区右侧 inset，并补回至少 24px 内侧 padding；长文案继续用内容 gutter 保持正文最大宽度和横向位置。滚动面的现有父级不得裁掉这 24px 扩展。每条产物渲染路径只能有一个滚动 owner：视频工程浏览态由 `video-browse` 承担，不能再由外层普通视频 preview 重复承担。无论文案、图片、数字人、普通视频、视频工程浏览态还是后续新增产物，只要在展示区产生纵向滚动，滚动条都必须贴住展示区最右边。禁止按 `.copy`、`.video` 等产物类型分别追加 margin 补丁。

### 5.4 素材可视化元素（跨界面复用）

- 缩略图容器 `.phbox`：`--surface-2` 衬底、9px 圆角、hairline 描边（真实产品中为图片，demo 中为渐变占位）
- 理解徽章「活的胶囊」：白底 hairline 胶囊 + 8px 渐变呼吸圆点 + 「已理解」；处理中用 `--warn` 圆点闪烁
- 被引用计数：`--ink-3` 小字或角标，凡素材出现处都带

### 5.5 视频产物：预览态 ⇄ 编辑态（复用现有内嵌编辑器，不自研剪辑组件）

现状：`product-workspace.tsx` 已将视频产物展示区实现为 `/editor?asset=…&embed=1` 的 OpenCut iframe（含 ready 握手与导出 postMessage 协议）。本设计**保留该编辑器作为唯一剪辑实现**，只在其外加一层很薄的预览壳：

- **预览态（默认）**：视频生成完成后，产物区显示 9:16 预览播放器 + 分镜摘要卡列表（含素材引用、MG 徽章、兜底标注）+ 来源引用块。先让商家看到「你的片子好了」，语义层（谁引用了哪张素材）在这里可见。修改优先走对话（「第 2 段字卡换成保修年限」）。
- **编辑态（点「编辑」原地切换，形态=胶片条）**：embed 模式的呈现层按「胶片条 + 分镜属性卡」重构（已选定，demo `docs/specs/ui/prototypes/current/screens/workspace-video.html` 为交互基准），不显示多轨时间轴：
  - **胶片轨**：单条，片段按时长比例分宽，标注序号/时长/兜底；点选与预览联动；选中片段两侧出现裁剪把手（拖动裁剪，单段 2–15 秒），「分割/删除」就地出现，无常驻工具栏、无标尺
  - **分镜属性卡**（选中即显示）：画面（当前素材 + 来源标注 + 换素材 → 素材选择器，AI 推荐排序）；配音（文本框直接改台词，字幕实时跟随，「重新配音」局部重合成）；MG 字卡（开关 + 文案，overlay 不占轨道，遵守 `mg_decision` 权威）
  - **成片属性行**：配乐（整条视频一个 BGM，chip 选择；有配音时整条保持固定低音量，不做动态闪避）
  - 底部：撤销 + 覆盖提示 + 总时长徽章；说明行「字幕会自动跟随配音文本 · 需要分轨调整？全屏打开 ↗」
- **全屏 `/editor` 保留**：完整多轨时间轴，承接分轨调整等专业需求，入口只在编辑态说明行；`docs/specs/ui/prototypes/current/screens/editor.html` 为其 V3 换肤视觉参考（换肤单独排期）。
- **两层数据边界（必须实现，且精确到操作）**：属性卡内的修改（换素材=`asset_reference`、配音文本=配音稿、MG=`mg_decision`、配乐）全部作用于分镜/成片语义层，可局部重合成，**AI 重排不覆盖**；胶片上的裁剪/分割作用于渲染层，**AI 重排前必须弹确认「会覆盖你的手工剪辑」**。界面提示语区分两者（「仅裁剪/分割会被覆盖；素材/配音/字卡修改不受影响」）。
- **明确不做**：多轨时间轴不进展示区；配音/字幕/动效不以轨道形式出现在内嵌编辑态。
- 交互细则：展开型切换必须保证新内容立即可见（原地替换或自动滚动到位）。

### 5.6 图片库 / 新建对话起始页

## 6. 动效规范

| 名称 | 用途 | 参数 |
|---|---|---|
| breathe | 渐变呼吸点/运行步图标 | scale 1→0.8 + opacity，2.2s ease 循环（运行步 1.6s） |
| sweep | shimmer 进度条 | translateX -55%→55%，1.8s ease 循环 |
| aur | 产物区极光 | opacity .65→1，5s ease-in-out alternate |
| blink-c | 打字光标 | opacity step-end，1s 循环 |
| blink | 待处理状态点 | opacity 1→.35，1.4s 循环 |

必须支持 `prefers-reduced-motion: reduce`：全部动画降级为静态（呼吸点定格、shimmer 换成静态渐变条、极光定格低透明度）。

## 7. 可用性与无障碍

- 正文对比度 ≥ 4.5:1（`--ink`/`--ink-2` 在 `--bg`/`--surface` 上已满足）；`--ink-3` 只用于辅助信息
- 主按钮高度 ≥ 36px，点击区不小于 40×40
- 渐变上的白字仅用于按钮短文案（字重 ≥600）
- V1 案的引导性文案作为可选点缀采纳：确认卡副标题（「都可以改…」）与复制后的下一步提示，在不增加视觉噪音的前提下加入

## 8. 落地路径（分阶段）

> 完整历史实施计划（文件级改动、接口约定、验收、灰度）见 `docs/archive/plans/2026-07-08-multimix-ui-redesign-implementation.md`，本节为概览。

**阶段 1 · 纯样式换肤（不动结构与数据）**
- 在 `MultiMix-Frontend/app/globals.css` 顶部 `:root` 替换为本规范 token（渐变类变量新增）
- 逐组件重写 `shadcn-prototype-*` 前缀下的现役样式（沿用现有前缀约定，不引入新顶层前缀）
- 覆盖：侧边栏、对话流气泡/芯片、确认卡两态、输入坞、产物卡、来源块、图片库卡片/抽屉、起始页
- 完成后即获得 C 系视觉 + 确认卡/来源块/徽章升级

**阶段 2 · 新增两个展示组件（需前端组件 + 后端事件）**
- `AgentRunTimeline`（Agent 执行时间线）：消费对话编排的真实步骤事件（理解/拆解/生成分段/排版），映射为商家语言；后端事件不足时先隐藏该卡，禁止假数据
- `AiBackgroundStatus`（侧边栏后台状态胶囊）：消费素材理解队列状态
- 生成态极光/打字光标/实时引用亮框：依赖流式生成事件，与 `product-preview.tsx` 生成态对接

**阶段 3 · 起始页与图片库完整落地**（按 5.6 节）；视频产物预览壳（5.5 节，预览态 ⇄ 现有 embed 编辑器切换 + 覆盖确认弹窗）在此阶段落地，编辑器 V3 主题换肤单独排期

每阶段完成后跑 `npm run typecheck` + `lint` + `test` + `build`，UI 关键路径截图对比 demo 基准稿。

## 9. 验收标准

1. 打开对话工作台，确认卡是页面上唯一渐变描边卡片；导航/次按钮/标签无渐变
2. 生成过程中：产物区出现极光 + 打字光标 + 实时引用亮框；生成结束后三者全部退场
3. Agent 时间线步骤与后端真实事件一一对应，无假进度
4. 素材在任何出现位置都能看到理解状态与被引用次数
5. `prefers-reduced-motion` 下无持续动画
6. 1280–1920 宽度无溢出裁切；`npm run build` 通过
7. 长文案、数字人准备方案和视频工程浏览态出现纵向滚动时，滚动条横坐标一致并贴住展示区最右边；正文横向位置与改动前一致
8. 产物区顶部按钮在所有产物状态下保持 30px 胶囊规格：主操作深色实底，详情 / 保存 / 导出白底描边；按钮功能、显示条件和禁用逻辑不因换肤改变

## 12. 能力降级规则（防「变形」，新能力缺位时的确定形态）

所有依赖新后端能力的组件必须按「数据不在就不渲染」实现，缺位时布局不塌、不留洞、禁止假数据：

| 组件 | 依赖 | 缺位时的降级形态 |
|---|---|---|
| Agent 执行时间线 | 生成任务步骤事件 | 整卡不渲染，退回「生成中 shimmer」；视频链路事件已有，先上视频 |
| 逐段出稿/打字光标/极光/实时引用亮框 | 流式生成 | shimmer 等待 → 一次性出全文 → 静态来源块 |
| 结构化确认卡 | 消息 payload 含 plan 对象 | 退回普通消息 + 建议芯片（现状） |
| 素材选择器 AI 推荐区 | 推荐端点 | 推荐区隐藏，仅图片库网格 |
| 分镜属性卡各行 | asset_reference / 配音稿 / mg_decision 字段 | 对应行隐藏 |
| 换素材/改配音「局部重合成」 | 单分镜重合成端点 | 退化为整条重编排，loading 文案按真实时长（分钟级）书写 |
| AI 后台状态胶囊 | 理解队列查询 | 无任务即隐藏（本为设计态） |
| 胶片条 | OpenCut embed 呈现层改造 | 暂用现有时间轴 embed，「编辑」槽位两者通用 |

后端验收三条硬约定：① 步骤事件粒度 ≥ 语义化 3 步（理解/规划/生成），否则时间线观感失效；② 局部重合成目标耗时 ≤ 30s；③ 流式出稿列入 backlog 并明确排期，不做则「生成过程即品牌」原则降半档，需产品知情。
