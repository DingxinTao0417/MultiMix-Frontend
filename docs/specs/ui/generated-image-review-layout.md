# 生成关键帧展示与审核布局

> Status: current
> Owner: frontend
> Last verified: 2026-09-07

## 背景

连续关键帧的展示区同时放置大图、右侧审核栏、缩略图和应用操作。大图与审核信息横向拆分，用户在检查单帧时需要来回移动视线；同一帧的状态也在多个区域重复出现。

## 已确认设计

展示区采用单列的“看图 → 审核 → 操作”顺序：

1. 顶部仅展示当前选中关键帧的大图。
2. 大图下方显示当前帧名称、图片数量、审核状态与“打开原图”。
3. 紧接着显示该帧的审核结果；审核状态、提示和差异项随 F01 / F02 / F03 的选择同步变化。
4. 右侧不再渲染缩略图；对话内的关键帧组是唯一的帧切换入口，保留帧号和简短状态。
5. “分别应用到分镜”紧接审核结果，仍是显式用户操作；不自动生成视频。
6. 大图画布使用展示区完整可用宽度，采用较宽比例并以中心裁切展示；不保留由竖图比例和最大高度共同造成的窄画布。
7. 审核结果使用紧凑信息条：状态徽章与帧名同一行，人工复核提醒保持一行；未发现差异时使用短提示，发现差异时才展示最多三项证据。

## 交互与状态

- 点击对话内缩略图更新受控的 `selectedFrameId`；右侧大图、标题和审核结果必须指向同一帧。
- 仅有一张图时保留单图审核与单图应用能力，无需在右侧添加选择控件。
- 多关键帧时保持批量应用映射、加载态和已应用状态不变。
- 审核结果为“未发现关键差异”时仍展示人工复核提醒；发现差异时展示最多三项差异证据。
- 大图采用 `object-fit: cover` 居中裁切，以较少的纵向高度换取完整展示区宽度；审核产品时仍可通过“打开原图”查看完整图片。

## 响应式规则

- 宽屏和窄屏均使用单列内容顺序，不再将审核结果固定为右侧栏。
- 对话内缩略图保持现有响应式布局；右侧不再保留缩略图横向滚动区域。
- 右侧画布与紧凑审核区均使用完整可用宽度，只保留外层统一内边距；不额外设置内容最大宽度或居中窄卡片。

## 验收

- F01 / F02 / F03 切换后，大图和审核结果同步切换。
- 页面不再出现独立的右侧审核栏、右侧缩略图或重复审核摘要。
- 三张关键帧的批量应用入口、状态与现有写入保护保持可用。
- 右侧画布铺满可用宽度，审核信息不再形成高留白的独立大卡片。
