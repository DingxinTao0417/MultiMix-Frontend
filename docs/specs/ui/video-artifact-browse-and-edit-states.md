# 编导稿与视频工程展示状态

> Status: current
> Owner: frontend
> Last verified: 2026-08-14

## 目标

明确区分编导稿、视频工程浏览态和视频工程编辑态，避免在编导稿中出现播放器，也避免点击视频工程产物卡后直接进入编辑器。

## 概念边界

- `素材` 是用户上传或系统匹配的图片、视频等原始输入。
- `分镜` 是视频工程中的一个时间段及其制作说明，包括时间、口播、字幕、`asset_reference` 和 `mg_decision`；分镜不等于已经渲染好的视频。
- `成片` 是全部分镜、素材、配音、字幕、转场和 MG overlay 合成后得到的一条连续可播放视频。
- 分镜卡片的数据优先级保持为 `video_project.segments -> video_segments -> video_plan.scenes`。
- 成片播放地址保持为 `video_project.mp4_ref -> mp4_artifact -> video_url / preview_url`。

## 产物卡切换

- 点击编导稿产物卡，展示区显示对应编导稿。
- 点击视频工程产物卡，展示区进入该视频工程的浏览态。
- 产物卡是编导稿与视频工程之间唯一的展示对象切换入口；展示区内部不增加对象切换 Tab。
- 当前选中的产物卡使用明确的选中状态。
- 视频工程产物卡的类别固定显示为“视频工程”，不得继承或同时显示来源编导稿的“编导稿”类别；历史工程若带有旧分类，展示时也必须按工程类型纠正。

## 编导稿展示

- 编导稿以连续文字内容为主体。
- 可以展示标题、版本、草稿或已确认状态和保存操作。
- 不展示播放器、播放按钮、播放进度、视频时间轴或分镜文字卡。
- 已确认并已创建工程的编导稿不得继续提示“确认后可生成视频工程”。

## 视频工程浏览态

- 点击视频工程产物卡后，默认进入浏览态，不直接进入编辑模式。
- 展示区最上方显示预览区。预览区必须明确标记当前是“成片预览”“分镜预览”还是“视频生成中”。
- 顶部操作区只保留进入编辑模式所需的“编辑”按钮，以及已有的必要详情或保存动作。
- 视频下方显示单列、纵向排列的分镜卡片。
- 分镜列表使用独立的纵向滚动区域；分镜数量增加时保持卡片可读尺寸，不分页、不折叠为“展开更多”，也不改成双列或横向胶片条。
- 成片预览时，点击任意分镜卡片会让完整视频跳转到该分镜起始时间并继续播放，不把主预览切换成原始分镜素材。
- 分镜预览时，点击任意分镜卡片会切换顶部当前预览的单个分镜，不把多个分镜自动串播成伪成片。
- 每张卡片最小展示：分镜序号、时间范围、缩略图、标题或口播摘要、素材状态，以及已有的“换素材”“修改配音”轻量操作。
- 卡片主体文字和右侧操作区必须分栏，不能把状态文字挤成竖排。

### 浏览态配音弹窗

- “修改配音”只在视频工程已 ready、存在真实工程资产且用户已登录时显示。
- 点击后打开与“换素材”一致的居中模态窗口，不切换到胶片条编辑态。
- 标题明确显示目标分镜序号；一次只打开一个分镜的配音窗口。
- 弹窗直接展示完整配音表单，支持修改口播、声音、语速、表达感觉和发音提示，并可生成试听。
- 试听不会修改稳定工程；应用成功后关闭弹窗，并刷新播放器、字幕、分镜口播和声音信息。
- “应用到全部分镜”提交前必须再次确认，避免从单镜入口误改全片。
- 配音任务运行期间禁止通过关闭按钮、Escape 或遮罩关闭；失败后保留草稿和试听，原视频不变。
- 浏览态与胶片条必须复用同一个配音编辑器和同一后端任务，不得形成第二套旁白状态。
- 裁剪、分割、排序和完整时间线操作仍属于编辑态，不因浏览态增加配音弹窗而迁移。

### 真人口播清理与导演确认

- 真人口播在生成稳定工程前使用两张顺序确认卡：先“清理确认”，再“导演确认”；不得合并为一步，也不得在清理冻结前生成可确认的导演方向。
- 清理卡按“自动、建议、保护”分组，逐项展示原话、处理方式、原因、预计缩短、音频风险和视觉跳切风险。自动项默认勾选，建议项可选，保护项默认锁定。
- 用户选择保护项时必须出现第二次确认，明确列出将覆盖的数字、否定、条件、结论、专有名词、引用、证言或低置信度边界；取消二次确认后保持保护。
- 多条有效人声音轨显示质量推荐与逐项试听；用户明确选中后才可确认。单一有效人声轨可以预选，但仍展示冻结结果。
- 卡片下方保留自然语言输入，允许“再紧一点”“只删口癖”“这句话保留”“恢复刚才所有重复”等表达；这些语义由 LLM 转换为结构化方案，界面不按关键词改勾选或时间线。
- 导演卡展示 2–3 个使用同一代表片段的动态样片、推荐理由、素材缺口和事件安排；选择提交明确的 `director_candidate_id`。至少两个合格样片即可继续，失败项提供独立重试。
- 清理或导演确认处于提交/生成中时锁定当前卡片；过期 plan/hash 或候选 ID 返回后刷新最新卡片，不能继续使用旧选择。
- 口播分镜卡展示权威原话、显示字幕、视觉事件、是否发布必需和素材缺口；普通“修改配音”不得替换真人原声，原话纠错与字幕显示修正必须是两个不同动作。

### 浏览态预览模式

| 当前状态 | 预览区 |
|---|---|
| 视频工程仍在生成 | 显示真实生成状态，不显示播放器或伪视频 |
| 视频工程已就绪，但没有可播放成片地址 | 显示默认第一镜的单分镜预览 |
| 存在可播放成片地址 | 显示完整成片播放器 |
| 成片加载失败，但分镜结构仍可读取 | 显示加载失败与重试入口，并允许查看单分镜预览 |
| 当前分镜没有素材 | 显示“待补素材”占位，不显示黑屏伪装的视频 |

单分镜预览规则：

- 分镜引用视频素材时，只播放当前分镜对应的视频素材。
- 分镜引用图片素材时，静态展示图片和该分镜时长，不模拟虚假播放。
- 分镜没有可用素材时，显示分镜标题、口播摘要和“待补素材”。
- 单分镜预览左上角显示“分镜预览 · #N”，避免被误认为完整成片。

### 播放器控制

- 成片播放器支持点击画面或播放按钮切换播放/暂停。
- 显示当前时间、总时长和可点击、可拖动的进度条。
- 成片播放过程中，根据真实播放时间自动高亮对应分镜。
- 点击分镜跳转时，使用该分镜从视频工程轨道投影出的真实开始时间。
- 视频保持工程原始比例，例如 16:9 或 9:16；不拉伸、不裁切，剩余空间使用中性背景填充。
- 原生视频加载失败时不得长期停留在无说明黑屏。

### 预览区尺寸拖动

- 视频预览区与分镜列表之间增加横向拖动分隔条。
- 向下拖动时增大预览区，向上拖动时缩小预览区。
- 调整的是预览区可用高度；视频本身始终按原始比例居中缩放。
- 设置最小高度，保证播放器控制可用；设置最大高度，保证分镜区仍保留可操作空间。
- 分隔条使用可访问的 `separator` 语义，并支持键盘方向键调整。
- 尺寸只在当前页面会话中保留；本期不跨刷新持久化。

## 视频工程编辑态

- 只有用户点击浏览态顶部的“编辑”按钮后，才进入编辑态。
- 编辑态复用当前胶片条编辑器，不跳转到独立的完整多轨编辑器。
- 编辑态仍属于当前视频工程展示区。
- 胶片条用于选择和排序分镜；选中分镜后编辑该分镜的素材、口播、字幕、时长和 MG overlay。
- 退出编辑态后返回该视频工程的浏览态，不返回编导稿。

## 状态流

```text
点击编导稿产物卡
  -> 连续文字编导稿

点击视频工程产物卡
  -> 有成片：顶部完整成片播放器
  -> 无成片：顶部单分镜预览
  -> 下方独立纵向滚动的分镜卡片

点击分镜“修改配音”
  -> 打开当前分镜的居中配音弹窗
  -> 试听不改工程
  -> 应用成功后关闭并刷新浏览态

拖动预览与分镜之间的分隔条
  -> 改变预览区高度
  -> 视频保持原始比例

点击“编辑”
  -> 当前展示区切换为胶片条编辑器

退出编辑
  -> 返回视频工程浏览态
```
