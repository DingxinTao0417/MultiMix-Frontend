# 方案 C 全站延伸（第三版，2026-10-14）

> Status: current
> Owner: frontend
> Last verified: 2026-10-14

以第一轮方案 C「成片优先」为基准，为首发范围内的页面各出一版视觉方案。探索稿，不影响 `prototypes/current/` 的验收基准。这是第三版，按复核意见修正了 9 处具体问题。

## 怎么看

打开 `index.html`：先是这一轮的修正清单，然后是仍然有效的关键设计决策、15 屏缩略图（可点开全屏）、逐页改造量和还没解决的问题。所有屏共用 `screens/c-system.css` 一套样式。

## 这一轮修正了什么

- 01 首页：不再是“登录页”，右上角「登录」按钮滑出登录面板；左侧用一条真实的 AI 生成样片做示例，流程示意跟着这条视频的真实镜头走。
- 02 入口卡：三个入口恢复横排三等分大卡，不再挤成细条；输入框独立占满宽度。
- 03 / 04 / 05 / 07：去掉胶片条和方案行旁边并排的信息卡，胶片条独占整行；细节用悬浮提示，完整参数放进详情弹窗。
- 04 / 05 / 09：补齐分辨率信息，按常规视频生成大模型的档位显示（480P / 720P / 1080P）。
- 08 导航面板：资源库四个按钮前置到最顶部，面板高度压缩到固定 560px。
- 12 图片库：处理状态筛选组移到右侧，和内容类型拉开间距。
- 15：删掉单独的管理后台无权限页，不占方案清单的一屏。

## 仍然有效的关键决策

- 播放台外壳固定，任何画幅放进去位置都不变，空出的部分用画面模糊放大填充。
- 分镜是播放台正下方独占整行的窄胶片条。
- 版本切换放在标题旁（v1 · v2 · v3 当前），详情弹窗里有完整版本记录。
- 拖拽调宽跟着布局走：凡是“展示区 + 对话轨”两栏就有分隔条，对话轨默认 400px，可拖 340–560px。
- 展示区不放确认类按钮；项目、视频、图片卡统一方形。
- “资产库”改名“素材库”；法务页保持原设计不动。

## 范围

- 剪辑器不在首发范围，没有出方案；各页面上的剪辑器入口已去掉。
- 只画了桌面 1440×900，未覆盖窄屏与移动端。素材画面均为占位色块。
- 原型里只演示了 9:16 和 16:9 两种画幅，1:1 和 3:4 沿用同一套逻辑。
- `assets/` 里三张入口照片复制自 `public/start-goals/`；`wan-*.jpg` 是从一条候选 AI 生成样片（`01-城市节奏-Wan3-22秒-720p.mp4`，用户提供，用户本机路径）截取的真实帧，仅用于本次原型展示，不构成首页正式案例的授权。

## 还没解决

- 首页示例视频如何正式接入，仍需走仓库里已有的「真实案例上架」计划的授权和质量确认流程。
- 视频真实分辨率的数据来源，需要后端确认成片记录是否已有该字段。
- 页面结构约定和播放器外壳都属于受保护内容，改动前需要用户明确批准。
- 素材库“AI 对你的了解”的生意概括后端没有现成字段，首发不做。
