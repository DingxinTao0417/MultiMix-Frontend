方案 C 全站改造：按复核意见修正的 15 屏

首发范围内的 10 个页面，15 屏。相对第二版，这一轮修正了 9 处具体问题：登录改首页、三个入口恢复横排大卡、补齐分辨率信息、去掉展示区里挤占空间或重复信息的侧栏、导航面板资源库前置并收窄、图片库处理状态挪到右侧、删掉单独的管理后台无权限页。

1这一轮修正了什么

按你的复核逐条修正：
  • 01 首页——不再是“登录页”，右上角一个「登录」按钮，点击滑出登录面板；左侧用一条真实的 AI 生成样片做示例（写实多镜头，22 秒，720P），流程示意跟着这条视频的真实镜头走，不再是抽象草图。
  • 02 入口卡——三个入口恢复成横排三等分的大卡（168px 高、真实照片 + 文字），不再挤成细条；输入框独立占满宽度。
  • 03 / 04 / 05 / 07 分镜与方案列表——去掉胶片条/方案行旁边并排的信息卡（它们抢了胶片条的宽度，内容和列表卡重复）。改成胶片条独占整行，格子加大；选中细节用悬浮提示，完整参数放进详情弹窗。
  • 09 / 04 / 05 分辨率——播放台控制栏、视频库精选卡和方形卡都补了分辨率：按常规视频生成大模型的档位显示（1080P / 720P / 480P），不写死某一个模型的真实输出。
  • 08 导航面板——资源库四个按钮挪到最顶部，面板高度从不限高压缩到固定 560px，最近项目收到 8 条。
  • 12 图片库——处理状态筛选组移到右侧，和左侧的内容类型筛选组拉开间距。
  • 15 管理后台无权限页——按你的意见删掉，不单独设计；普通账号直访问时用通用的「没有权限」提示，不占方案清单的一屏。

2仍然有效的关键设计决策

播放台：外壳固定，任何画幅都能放

位置
始终在展示区上方，分镜胶片条始终在它正下方。横屏、竖屏，以后加别的尺寸，位置都不变。
空出来的部分
用当前画面的模糊放大版填充，不留纯黑边。
外壳加重
深色厚外壳 + 底部控制栏（时间码、分镜刻度、画幅、分辨率、素材来源），比之前的白壳更像“放映台”。

分镜：窄胶片条独占整行，不再分走空间

胶片条
每格方形缩略图 + 序号 + 时长 + 来源色点，宽度铺满展示区。
细节
悬浮显示这一镜的素材出处和台词；完整参数在详情弹窗里。
说这镜
每格常驻，点一下对话输入框就绑定到这一镜。

版本：切换放到标题旁边

切换条
标题旁直接显示 v1 · v2 · v3 当前，一点就能看那一版。
每版一句话
对话里写明“v3 第 3 镜换成你的安装视频 · 之前的版本都还在”。
用回旧版
会生成新版本，原来的全部保留。详情弹窗里有完整版本记录。

拖拽调宽：跟着布局走

规则
只要页面是“展示区 + 对话轨”两栏，就有分隔条，宽度在同一个项目里保持不变。
数值
对话轨默认 400px，可拖 340–560px，双击恢复默认。
没有分隔条
首页、新建项目、单栏对话、资源库、管理后台。

展示区不放操作按钮的原则

确认
文案稿的“稿子满意了？”挪进对话里，成为助手发出的确认卡。
展示区只有
阅读、播放、版本切换，以及导出、保存这类产物自身的动作。

少留白与命名

留白
内容区随窗口铺开，两侧只留 24–28px。首屏能放下的内容不靠滚动。
方形卡
项目、视频、图片库统一方形卡，画幅用角标标注。
改名
“资产库”改为“素材库”，导航、页面标题同步。

315 屏方案

按用户真实路径排序：首页 → 新建 → 对话 → 生成 → 完成 → 其他产物 → 导航与资源库 → 管理 → 重置密码。点卡片打开全屏。

01首页中

不再是登录页；右上角「登录」按钮滑出面板；左侧用真实样片示例，流程跟着真实镜头走。
02新建项目小

输入框独立占满宽度；三个入口恢复横排大卡；最近项目方形卡一屏放完。
03对话 · 待确认中

单栏铺宽，确认卡里预览 5 镜，补了分辨率；按钮不被挡。
04视频生成中大

胶片条独占整行、格子加大；控制栏补分辨率；进度只显示真实阶段。
05视频完成大

版本切换在标题旁；胶片条独占整行；补了分辨率；偏好记忆在对话里。
06文案产物中

展示区只读；确认卡挪进对话；有版本切换。
07图片产物中

方案行独占整行，不再有并排信息卡；外壳贴合图片。
08导航面板小

资源库四个按钮前置到最顶部；面板整体高度压缩到 560px。
09视频库中

方形卡带画幅角标和分辨率，横竖屏混排整齐；精选卡带素材构成。
10素材库中

改名素材库；顶部只放统计和最常用，不放“生意概括”。
11文案库小

独立页面；台词开头当预览，一屏八张。
12图片库小

内容类型在左、处理状态在右，两组拉开明显间距。
13资源详情弹窗中

只放平时看不到的参数；版本记录在这里，可预览、可用回。
14管理后台小

标注“仅管理员可见”；漏斗终点是导出或下载。普通账号的无权限提示不再单独设计。
15重置密码小

复用首页登录面板同一套左栏，不再左侧空着。

4逐页改造量

「大」= 改布局与交互逻辑；「中」= 调整组件结构；「小」= 只换样式。法务页保持原样，没有改动。

页面改动量主要牵动
首页 · 重置密码中首页从登录页改成带滑出登录面板的首页，两页共用一套左栏；需要接入示例视频片段
新建项目小起始页组件；最近项目要拉取画幅、时长与分辨率

5还没解决的问题

这些我在原型里没法替你定，需要你拍板或后端确认：
  • 首页示例视频的接入方式。原型用的是一段 AI 生成的真实样片截帧，仅用于原型展示；真要上线首页，仍需走仓库里已有的「真实案例上架」计划的授权和质量确认流程，不能直接用这段样片替代。
  • 视频真实分辨率从哪里来。原型按常规视频生成大模型的档位（480P/720P/768P/1080P）画，具体某条视频属于哪一档取决于它用的生成模型，需要后端确认成片记录里是否已有这个字段，没有的话由谁来推算。
  • 页面结构约定要改。现行设计文档写的是对话在左、宽度 480–720px。这一版是对话在右、340–560px，需要你批准后同步改设计文档、拖拽边界和测试。
  • 视频播放器外壳要改。从白色外壳改成深色厚外壳，是受保护的视觉约定，需要你当次明确批准，并同步更新契约检查和截图基线。

6确认后的推进顺序

第一步
样式底座

统一颜色、卡片、按钮。首页、重置密码、管理后台、导航面板可以一起换，风险最低。

第二步
工作台重构

主区与对话轨对调、新播放台、胶片条、版本切换条、拖拽分隔条。先改设计文档，再动代码。

第三步
产物页与资源库

文案、图片产物页，四个资源库和详情弹窗。依赖后端的部分先用现有数据占位。
