● 2026-10-11 · 侧栏弱化方案（配合 B 批注式修改）

最左侧侧栏弱化：四个方案

目标是把视觉重心让给成片与分镜，同时不牺牲「继续做某个项目」这个侧栏主任务。 四个样本按真实 CSS 比例还原，右侧工作区保持恒定，方便直接比较重心变化。

先说结论：侧栏最重的一块不是宽度，是资源库那四张卡。
它们每张都有白色卡面、边框、阴影和一个彩色图标底座（globals.css:493 起，min-height:54px）， 四张合计约 115px 高（两行 54px + 7px 间距），是侧栏里最抢眼的区域。但按设计文档，资源库只是「查找、复用和管理已有资源」的工具， 不是新建视频的主要入口。现在最重的视觉给了最次要的任务。推荐 S2：弱化外观 + 把资源库降为文字行。

    省出约 44px（115px → 71px），最近项目可见条数变多

3建议

推荐 S2，并与 B 方案同轮落地

  1. 资源库从 2×2 彩色宫格改为四行纯文字，与项目行同款高度和字号，只用浅色圆点区分。 这是侧栏弱化收益最大的一步：它同时去掉了彩色噪点、卡面阴影，并把该区高度从约 115px 降到约 71px。
  2. 侧栏底色并入页面（#f8f6f3 → --bg），只保留右侧 1px 分隔线。 左侧不再是一块"面板"，而是页面边缘的一列文字。
  3. 宽度 264px → 236px，省出的宽度按设计文档规则优先分配给展示区。
  4. 「新建项目」保留深色实底。弱化不等于全部变淡，它是侧栏唯一的创建动作，应当是侧栏里最显眼的一个元素。
  5. 最近项目保持现状不动，默认 8 条 + 「查看全部」。弱化完成后它自然成为侧栏主角，不需要额外加强。
需要你明确批准的一点：V3 设计规范第 5.1 节与工作台设计第 3 节把「资源库 2×2 轻量卡片」写成已确认决策。 改成文字行属于推翻该决策，按工作区规则必须有你当次的明确批准，并同轮更新规范、当前原型和实现三处，不能只改实现。 你说「弱化侧栏」我理解为已经认可方向，但 2×2 这条具体决策我不替你改，请确认是否连这条一起改。

4不建议动的部分

  • 保留
    最近项目列表本身。设计文档明确侧栏以「继续项目」为主要任务。弱化的对象是装饰，不是这个列表。
  • 保留
    项目状态文字（生成中 / 待确认 / 需处理）。这三种有行动价值，且已按规则做成纯文字右对齐，不是噪点。
  • 保留
    AI 后台状态胶囊。它是渐变纪律允许的「AI 正在参与」时刻，且无任务时整条隐藏，不构成常驻权重。
  • 注意
    不要靠调淡文字颜色来弱化。规范要求正文对比度 ≥4.5:1，--ink-3 只能用于辅助信息。 弱化应当靠去掉卡面、边框、填充和阴影实现，不是把字变浅。
  • 注意
    品牌 mark 的渐变圆底可一并改为单色。品牌规范已确认 LOGO 主版本为黑白极简、不使用紫青渐变， 当前侧栏仍用渐变圆底，与品牌规范存在口径差。顺手改成单色会更一致，但这属于额外一项，你可以单独定。
