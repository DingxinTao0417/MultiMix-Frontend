# UI Exploration Prototypes

> Status: current
> Owner: frontend
> Last verified: 2026-10-16（补 10-13 三轮探索与方案 C 定稿状态）

这些原型记录 UI 设计探索过程，只用于理解方案选择，不作为当前实现基准。

- `2026-07-08-round1-visual-style/`：三种视觉风格探索，用户选择 C 系方向。
- `2026-07-08-round2-space-model/`：三种空间范式探索，用户决定保留工作台骨架。
- `2026-07-08-round3-workbench-options/`：工作台三案探索，用户选择 V3 智能体工作台。
- `2026-09-24-conversation-empty-template-options/`：已有对话尚无产物时的视觉选型，以及“创作开始 / 制作过程中”两种对话创作教练形态。
- `2026-10-11-uiux-positioning-review/`：UI/UX 与已确认定位的契合度只读审查，含定位承诺逐条落点核对、已确认问题分级，以及「局部改」放在哪里的三个布局/交互方案（A 常驻修改栏 / B 批注式修改 / C 成片为中心）与推荐。用户已于 2026-10-11 选定 B。
- `2026-10-11-sidebar-de-emphasis/`：配合 B 的左侧侧栏弱化选型，四个真实比例样本（S0 现状 / S1 降噪 / S2 降噪+资源库降级 / S3 默认折叠图标轨）与推荐 S2。其中「资源库 2×2 宫格改纯文字行」会推翻 V3 规范已确认决策，等待用户明确批准后才可执行。
- `2026-10-11-sidebar-free-navigation/`：不占用左侧区域的按需导航选型，四个样本（N1 顶栏项目切换器 / N2 命令面板 / N3 全屏项目台 / N4 悬浮迷你轨）与推荐 N1。去掉左栏会改动工作台设计第 3 节与 V3 规范第 4 节的已确认三区骨架，并需同轮更新七屏原型与截图基线；等待用户确认方向及「单独窗口」的具体含义。

2026-09-24 的空态模板及右侧创作教练已被后续产品决策取代，原型仅供历史参考，不代表当前界面或开发待办。当前规则是无真实产物时保持单栏对话，提示词推荐在对话中完成；见 [工作台设计](../../../../MULTIMIX_WORKSPACE_DESIGN.md)。

- `2026-10-13-premium-agent-visual-directions/`：界面审查与第一轮 4 个视觉方向（A 深色影棚 / B 杂志级亮底 / C 成片优先 / D 双色影棚），用户选 C。
- `2026-10-13-premium-agent-visual-directions-round2/`、`…-round3/`：第二、三轮方向 E–L（时间线、分镜卡组、剧本稿、取景器、节点画布、沉浸影院、控制台、画廊），作为对照，未采用。
- `2026-10-13-canvas-first-full-site/`：方案 C 全站延伸 15 屏，**2026-10-16 已定稿**，代码改版时转为正式原型；改版前不作为验收基准。见该目录 README。

当前验收基准仍是 `../current/`（方案 C 代码改版前）。
