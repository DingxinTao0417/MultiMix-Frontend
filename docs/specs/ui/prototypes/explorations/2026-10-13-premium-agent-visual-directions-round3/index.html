第三轮视觉方向：I–L

这一轮按你说的，不管白播放器外壳、不管对话区宽度、不管渠道合规。四个方向各自挑战一条原来认为不能动的东西，所以它们不是「可以直接落地的候选」，而是用来问「如果那条约束不存在，界面会变成什么样」。

先说清楚：这四个都会和现有契约冲突，有的还需要新的交互能力（画布拖拽、长行程推子）。我没有在页面里回避这些代价，每个方向下面的「代价」一栏写的是真实成本，不是形式上的风险提示。前两轮存档在 第一轮 和 第二轮。

1四个方向

内容依旧是同一条 32 秒隔音视频、同样 5 个分镜，只有结构和气质不同。

方向 I

Node Canvas · 血缘画布

把素材、分镜、成片摊在一张可缩放的画布上，用连线显示引用关系：哪份素材喂给了哪一镜、哪一镜汇进了成片。公开素材那条线是黄色虚线，第 2、4 镜共用一张图也直接看得见。对话退成浮在画布上的玻璃面板。

打开全屏 ↗

强项

  • 素材来源从标签升级成结构：虚线就是「这不是你的」，无法忽略
  • 素材复用关系（2、4 镜共用一张图）只有连线能表达
  • 改引用变成拖线，比翻菜单找素材直观
  • 天然支持多条草稿并置，一张画布上比较 A/B 版本

弱点

  • 成片被降格成画布上的一个节点，重量感不如 C/J
  • 节点图是工程师的语汇，商家可能只认中间那列分镜
  • 5 镜就已经占满 1440 宽，镜数一多必须缩放才看得全
  • 浏览态引入了「空间位置」这个新状态，需要持久化

代价

  • 需要画布引擎：缩放、平移、连线命中判定、拖拽改引用
  • 连线布局要自动算，手写坐标不可维护
  • 最大的一个：这是四个里工程量最高的
方向 J

Immersive Cinema · 沉浸放映

没有面板，没有分栏。成片居中悬浮，自己的颜色晕染成整个窗口的背景光。所有 UI 都是浮在上面的玻璃：项目名在左上、胶片条在底部、对话是左下角一列渐隐的字，连气泡框都省了。右下角两枚色点说明素材构成。

打开全屏 ↗

强项

  • 成片重量感四个里最强，整个窗口都在为它服务
  • 氛围光让产物看起来「贵」，而这不依赖任何装饰元素
  • 对话不占版面：渐隐的一列字，看完自然消失
  • 胶片条把时长和来源压缩进 107px，信息密度意外地高

弱点

  • 字幕、台词这些需要逐字改的东西，这里没有地方放
  • 玻璃层叠加毛玻璃模糊，低端机上会掉帧
  • 深色沉浸和「白天在店里用手机看」的真实场景相悖
  • 没有面板边界，新用户不知道哪里可以点

代价

  • 需要从成片抽主色做氛围光，这是一套取色管线
  • 浅色模式基本无法复用，等于维护两套视觉
  • 中等，但可访问性（对比度）要专门过一遍
方向 K

Console · 调音台

每一镜是一条通道条。推子的高度就是这镜的时长，旁边那根是配音电平，顶上的灯绿色代表你的素材、黄色代表公开素材。左边是对讲，右边是总输出：成片小窗、素材构成比例、配乐与字幕状态。顶部是走带条和 LED 时码。

打开全屏 ↗

强项

  • 时长对比一眼可读：推子高度差就是节奏差，比数字强得多
  • 「专业设备」的质感最足，也最不像文档工具
  • 来源灯、字卡开关、时长推子三件事在同一条里，改动闭环短
  • 总输出栏把素材构成做成了比例条，发布前的体检表

弱点

  • 推子、电平、走带都是剪辑师的语汇，门槛四个里最高
  • 画面只有 84px 预览，换素材这类视觉判断依据不足
  • 通道条宽 150px，8 镜以上必须横向滚动
  • 拟物质感（内阴影、金属渐变）维护成本高且容易过时

代价

  • 需要长行程推子组件，且要能键盘操作
  • 电平表若要真实跳动，得接音频分析
  • 中等偏大，拟物细节会显著拉长实现时间
方向 L

Gallery · 展陈

成片当展品挂在墙上，下面是一块铭牌：形制、结构、用途、配音，以及最关键的来源构成和一枚「来源已标注」的印记。五个分场在同一视线高度排开，每张展板下有自己的小铭牌写着台词和出处。对话变成右侧的策展说明。

打开全屏 ↗

强项

  • 把「来源标注」从合规负担变成了品质声明，这是个视角反转
  • 高级感完全来自留白和字体，不依赖深色或渐变，最省维护
  • 浅色、打印友好，商家截图发给客户看也不难看
  • 铭牌格式能平移到长文案、图文笔记等非视频产物

弱点

  • 节奏感最弱：五张展板一样大，看不出哪镜长哪镜短
  • 大面积留白在 1440 宽下很舒服，笔记本 13 寸上会显得空
  • 「美术馆」的隐喻对卖门窗的商家可能过于文雅
  • 没有播放器外壳，成片和分场的层级靠尺寸区分，不够硬

代价

  • 需要铭牌组件和一套排版规范（字号阶、留白阶）
  • 衬线中文在 Windows 上的回退要实测
  • 最小的一个：基本是排版工作，没有新交互

3我的读法

J 和 L 是一对反向答案。同样想让产物显贵，J 用光，L 用留白。J 适合「看成品」，L 适合「审稿」，两者可以是同一产物的两个视图，而不是二选一。
I 和 K 都在暴露内部结构，区别是 I 暴露空间关系（什么来自哪里），K 暴露时间关系（哪镜多长）。I 的血缘连线解决的是信任问题，K 的推子解决的是节奏问题——这两个问题都真实存在，但没必要用同一种控件。
最省的组合：L 的铭牌 + K 的推子。铭牌管来源和形制，推子管时长，都不需要画布引擎，也不破坏浅色底。

4需要你决定

三个决策点

  1. 要不要深色I/J/K 都是深色，L 是浅色。深色让成片显贵但要维护两套视觉，这个成本值不值得。
  2. 来源标注往哪个方向做I 把它做成连线，K 做成指示灯，L 做成铭牌印记。三种都比现在的小标签强，但气质完全不同。
  3. 节奏信息要不要进浏览态只有 K 把时长做成了可读的视觉量。如果这件事重要，K 的推子可以单独摘出来嵌进别的方向。
