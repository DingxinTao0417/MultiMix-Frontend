# 第二轮视觉方向：E–H（2026-10-13）

第一轮之后的续探。第一轮的 A/B/D 是同一个两栏骨架在换配色，容易看起来重复；这一轮换的是**结构**——主产物以什么形态存在、修改从哪里发起。方案 C 保留为基准。

## 怎么看

打开 `index.html`：C 的预览放在最前面作对照，后面是四个新方向的实时预览、强项与风险，再往下是横向对比表和决策点。

| 文件 | 方向 | 主产物形态 |
| --- | --- | --- |
| （第一轮）`c-canvas-first.html` | 成片优先 · **保留基准** | 一条片子 + 一组分镜卡 |
| `screens/e-timeline-native.html` | 时间轴原生 | 一条贯穿底部的多轨时间轴 |
| `screens/f-storyboard-deck.html` | 分镜牌组 | 一组可拖动的分镜牌，无常驻播放器 |
| `screens/g-script-manuscript.html` | 剧本稿 | 一份拍摄脚本，成片退到页边 |
| `screens/h-viewfinder.html` | 取景框 | 手机框里的成片，还原顾客视角 |

四个页面内容完全相同（同一条 32 秒隔音视频、同样 5 个分镜），只有结构不同，便于直接对比。

## 可以叠的组合

C + H 最自然：C 的骨架不变，只把中间的白播放器换成取景框。C + F 也成立：F 的牌组是 C 分镜卡的加强版，差别只在要不要保留常驻大播放器。E 和 G 是两个相反极端，选一个基本排除另一个。

## 需要确认

1. 主产物是什么形态——片子、牌、时间轴还是脚本
2. 浏览态要做到多深——E 把时间轴放进浏览态后，编辑器全屏态还剩什么职责
3. 白播放器外壳契约是否可改——F 让它无处落地，H 用手机壳取代它
4. 要不要模仿小红书界面——H 的核心价值来自这里，但有合规与跟版成本

## 范围与状态

同第一轮：只画了桌面 1440×900 的视频工作台，未覆盖起始页、资源库、编辑器全屏态和移动端。探索阶段，不影响 `prototypes/current/` 的验收基准。
