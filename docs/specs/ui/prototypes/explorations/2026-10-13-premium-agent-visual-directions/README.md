# 界面审查与 4 个视觉方案（2026-10-13）

未定稿的视觉探索。目的是回答两个问题：当前界面离「高级」和「AI Agent 感」差在哪，以及有哪几条可选的解法。

## 怎么看

打开 `index.html`，里面有审查结论、四个方案的实时预览和横向对比。四个方案各自是可独立打开的完整页面：

| 文件 | 方案 | 一句话 |
| --- | --- | --- |
| `screens/a-studio-noir.html` | 深色影棚 | 整体进暗房，画面是屏幕上唯一光源 |
| `screens/b-editorial-light.html` | 杂志级亮底 | 留在亮底，靠排版和细线表格做高级感 |
| `screens/c-canvas-first.html` | 成片优先（推荐） | 成片占主区，对话收成右侧工作轨 |
| `screens/d-dual-tone-studio.html` | 双调工作室 | 左亮右暗，铜橙单色信号替代紫青渐变 |

## 审查结论

当前界面规则正确性已经很完整，问题在视觉：像文档工具而不像视频制作工具。三个主因是成片在页面上没有重量感、紫青渐变已是 AI 产品通用符号、全页层级过平。交互上最大的问题是分镜被藏进编辑态，而分镜才是短视频的修改单位。

## 范围

四个方案只画了桌面 1440×900 的视频工作台，因为高级感主要在这一屏被决定。未覆盖起始页、资源库、编辑器全屏态和移动端。方案选定后再延伸其余屏幕。

## 状态

探索阶段，不影响 `prototypes/current/` 的验收基准。四个决策点（明暗方向、是否换掉紫青渐变、对话与结果谁占主区、分镜是否在浏览态可操作）需要确认后才动代码或改设计文档。
