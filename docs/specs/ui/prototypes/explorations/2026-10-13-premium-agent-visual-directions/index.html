界面审查与 4 个视觉方案

审查对象是当前验收基准原型（起始页、文案工作台、视频工作台、资源库）。四个方案都重画了「视频工作台」这一屏，因为高级感和 Agent 感主要在这一屏被决定。

结论：当前界面在规则正确性上已经很完整，但视觉上像一个文档工具，不像视频制作工具。三个主因：亮纸底让视频内容失去对比、成片在页面上没有重量感、紫青渐变是 2023 年 AI 产品的通用符号。四个方案里推荐 C（成片优先），它在不推翻现有产品规则的前提下，最直接地解决「结果不够像主角」。

未覆盖：起始页、资源库、编辑器全屏态、移动端。方案只画桌面 1440×900 的视频工作台；采纳后再延伸其余屏幕。

1当前界面的问题

按对高级感和 Agent 感的影响排序，不含功能性缺陷。

视觉层面

  • P0成片没有重量感。白播放器放在亮纸底上，边界几乎消失，用户最该骄傲的交付物看起来像一张占位图。
  • P0紫青渐变已是通用符号。这组颜色出现在大量 AI 产品里，用它表达「AI 在参与」不再有辨识度，也不传达视频行业感。
  • P1层级过平。全页同一种白底、同一种 hairline、同一种 16px 圆角，视线没有落点，密度看起来松散而不是克制。
  • P1缺少专业工具语汇。没有时间码、没有等宽数字、没有分镜时长比例，看不出这是处理时间轴媒介的工具。

交互层面

  • P0分镜被藏进编辑态。短视频的修改单位就是「第几镜」，但浏览态只给摘要卡，用户要先点「编辑」才看得到可操作的分镜。
  • P1素材出处要靠展开才看见。「用了你哪张素材」是本产品最强的信任点，却默认收起在来源摘要里。
  • P1对话与结果争夺注意力。52% 宽度给对话，结果被压在右侧；但完成后用户真正要看的是结果。
  • P2建议芯片形态偏弱。胶囊排成一行，看起来像标签而不是可执行的下一步。

2四个视觉方案

下面每个方案都是可点开的真实页面，预览框里是等比缩小的实时渲染。

方案 A

Studio Noir · 深色影棚

整个工作台进暗房，画面成为屏幕上唯一的光源。白色播放器外壳在暗底上自动变成灯箱，分镜条按时长比例分宽，像真正的胶片轨。

打开全屏 ↗

强项

  • 成片对比度最高，视频一眼成为主角
  • 和文档类工具彻底区分，专业器材感最强
  • 白播放器外壳契约原样保留，变成优势

风险

  • 目标用户是白天在店里看屏幕的商家，暗色在强光下反光、可读性下降
  • 长文案产物在暗底上阅读负担变大
  • 与现有亮底品牌资产、登录页需要同时重做

改造量

  • 需要整套暗色 token 与全部组件适配
  • 截图基线、视觉契约测试全部重拍
  • 最大：约等于一次完整换肤
方案 B

Editorial Light · 杂志级亮底

保持亮底，但把高级感换一条路实现：靠排版、留白和细线表格，不靠渐变。圆角收到 4px，气泡换成竖线引注，分镜改成带缩略图和来源标注的清单。

打开全屏 ↗

强项

  • 分镜清单信息量最大：台词、素材出处、时长一屏看全
  • 白天店内可读性最好
  • 素材来源默认可见，信任点被放到明面

风险

  • 直角细线的「编辑部」气质偏冷静，不如暗色有视频行业感
  • 成片的重量感仍依赖阴影，不如暗底直接
  • 衬线标题在中文下字体可得性要实测

改造量

  • 复用现有亮色体系，改圆角、间距、字阶
  • 分镜浏览态要新增清单组件
  • 中等：视觉基线改动但不换色彩体系
方案 C · 推荐

Canvas First · 成片优先

翻转主次：成片和分镜占据左侧主区，对话收成右侧 30% 的工作轨。分镜变成带缩略图的卡片网格，每张都常驻「说这镜」，输入框顶部显示「正在说第 1 镜」。

打开全屏 ↗

强项

  • 直接解决 P0：结果成为页面主角，成片有明确重量感
  • 分镜卡在浏览态就能点、能说，修改单位和产品心智一致
  • 右轨保留完整对话、确认卡和真实阶段进度，Agent 在场感最清楚
  • 沿用现有亮色与渐变体系，不动品牌资产

风险

  • 对话宽度从 52% 降到 30%，长回复和长文案产物要另找承载方式
  • 与现行文档「对话区 clamp(480px,52%,720px)」的页面结构约定冲突，需用户确认改契约
  • 尚无产物时的单栏居中态要单独定义

改造量

  • 主要是布局反转和分镜卡组件，色彩体系不变
  • 需改页面结构文档、拖拽边界与 ARIA 上下限
  • 中等偏小：视觉 token 基本复用
方案 D

Dual-Tone Studio · 双调工作室

左亮右暗：对话留在亮纸底保证白天可读，展示区进暗色放映厅让画面发光。同时把紫青渐变换成单色铜橙信号色，分镜行以时间码起头。

打开全屏 ↗

强项

  • 兼顾白天可读与影院感，成片重量感接近方案 A
  • 铜橙单色信号最有辨识度，摆脱通用 AI 渐变
  • 时间码起头的分镜行专业感强

风险

  • 明暗分界需要极强纪律，做歪就显得拼贴
  • 换品牌信号色会波及 LOGO 以外的全部强调色、登录页和营销素材
  • 展示区内的长文案产物仍在暗底上阅读

改造量

  • 需要双套 token 并明确每个组件归哪一侧
  • 确认卡、徽章、按钮的强调色全量替换
  • 较大：布局不变但色彩体系重定义

4需要你决定

这些问题决定下一步落哪个方向，不选完不动代码。

四个决策点

  1. 明暗方向整体亮底（B/C）、整体暗底（A），还是左亮右暗（D）？这决定后续全部屏幕的基调，也决定改造量级。
  2. 要不要换掉紫青渐变换成单色信号（如 D 的铜橙）辨识度更高，但会波及登录页、品牌材料和全部强调色。
  3. 对话和结果谁占主区方案 C 把对话压到 30%。这会改动已沉淀的页面结构约定，需要你明确批准。
  4. 分镜是否在浏览态就可操作四个方案都这么做了。这是产品心智改动，不只是视觉。
