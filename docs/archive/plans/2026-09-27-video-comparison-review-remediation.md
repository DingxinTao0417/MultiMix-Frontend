## 背景与根因

2026-09-27 对当前未提交的视频版本对比改动做只读复查，发现首次进入时自动选中第一条差异；如果它是新增/移除分镜，会立即遮挡一侧的完整视频。选择分镜后详情在差异列表下展开，但页面同时滚回播放器，导致详情离开视野。差异计算把缩略图 URL 当作画面变化，且播放失败无论错误原因均被提示为浏览器自动播放限制。素材更换摘要还需要确保 `asset_reference.chosen_asset_id` 与已持久化 saved asset 主画面身份一致。入口字号 11.5px 低于现行 12px 元信息规范。

## 具体改法

1. 对比入口保持中立：初始不选中任何差异、不显示单侧遮挡，两个播放器都可浏览。用户点选差异后才定位、自动播放并在新增/移除镜时遮挡缺失侧；未选中时不显示“已跳转”状态。
2. 保留点击差异跳转播放器的主交互，同时把当前差异的前后值放到播放器下方的对比区内展示，避免详情仍停留在视窗外的列表行；键盘焦点提供可见且合理的去向。
3. 缩略图地址变化不再单独算作画面变化。素材替换文案要求前后引用 ID 不同，且分别与各自已持久化 `saved_asset` 主画面 ID 一致；只改变缩略图或引用与实际主画面不一致时不宣称替换。
4. 按媒体错误类型区分自动播放被拒、播放被中断和真正解码/媒体错误，显示与原因相符的短提示。
5. 差异入口元信息字号不小于 12px；同步设计文档与当前原型。

## 风险与取舍

- 中立初始态意味着用户进入后先看到完整前后版本，差异定位需显式点击；这避免系统擅自把第一处增删认作当前检查目标。
- 播放器下方展示详情会调整差异详情的位置，但仍保留唯一差异列表与点击跳转，不重复分镜卡。
- 历史主轨缺少可靠素材身份时，摘要宁可不说“素材已更换”，用户仍可播放两版核对。
- 不改变播放器外壳、画布比例、音频单侧试听规则或生产数据。
