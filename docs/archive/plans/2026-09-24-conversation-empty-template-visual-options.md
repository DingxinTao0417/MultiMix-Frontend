# 对话初期空展示区：模板视觉三案探索

> Status: archived
> Owner: frontend
> Last verified: 2026-09-28

> 归档说明：本探索已被后续产品决策取代。首个真实产物出现前不渲染右侧展示区，提示词推荐属于对话消息；以 `MultiMix-Frontend/docs/MULTIMIX_WORKSPACE_DESIGN.md` 为当前设计依据。原型仅保留为历史探索，不代表待实施方案。

## 背景与根因

已有对话在尚未形成产物时，右侧展示区需要承担轻量教程和创作启发作用。此前的阶段教程画布虽然避免了卡片堆叠，但普通澄清阶段仍然偏说明文，无法帮助用户快速理解“我现在可以怎样开始”。本轮不修改正式界面，只制作三套放入真实工作台结构中的视觉原型，供用户比较后再决定生产实现方向。

## 涉及文件与关键位置

- `docs/specs/ui/prototypes/explorations/2026-09-24-conversation-empty-template-options/index.html`：在同一真实工作台壳中提供 A「任务模板架」、B「从现有素材开始」、D「风格样片橱窗」三个可切换方案。
- `docs/specs/ui/prototypes/explorations/README.md`：登记本轮探索入口。
- `docs/archive/plans/2026-09-24-conversation-empty-template-visual-options.md`：记录历史设计边界、取舍与验收方式。

## 具体改法

1. 保留当前桌面工作台的侧栏、对话区、标题区和输入区比例，只替换右侧无产物区域，确保比较的是内容策略而不是三套无关产品壳。
2. A 案使用三条横向任务配方，每条同时展示输入条件、微型分镜和预期结果；它负责回答“我能做什么”。
3. B 案以四类起始资料构成连续路径，并显示每类资料如何转化为内容；它负责回答“我手里的东西能怎么用”。
4. D 案以三张大幅样片和节奏标签展示表达方式；它负责回答“成片可能长什么样”。
5. 三案都不新增第二输入框，不显示虚假进度、资料数量或已经完成的系统判断；顶部切换器仅用于本轮视觉比较，不属于正式产品设计。

## 风险与取舍

- 模板如果过多，会把对话工作台误导成模板商城，因此每案只保留 3–4 个高辨识度入口。
- 右侧模板若进入正式产品，需要重新确认它与“操作留在左侧对话”的现行规则关系；本轮只验证视觉与信息密度，不决定交互合同。
- 风格样片需要真实或可授权的封面素材；本轮使用 CSS 构造的抽象画面，不代表最终内容资产。

## 验证方式

1. 使用本地静态 HTTP 服务打开原型，分别检查 A、B、D 三案的桌面截图。
2. 在窄屏视口检查侧栏隐藏、对话区和展示区纵向排列、切换器与内容无横向溢出。
3. 运行 `npm --prefix MultiMix-Frontend run docs:check`，确认新增计划与探索入口符合文档规则。

## 本轮探索结果

- 已在统一的真实工作台壳中完成三个可切换方案，左侧固定为“已有首轮对话、尚无产物”的同一上下文。
- A 案采用无外层卡片的横向任务配方，突出任务、微型分镜和预期结果。
- B 案采用来源到可编辑工程的连续转换图，突出想法、图片、原视频和文档的用途。
- D 案采用三联竖屏样片，突出真实纪实、极简讲解和节奏混剪三种表达感受。
- Playwright 在 `1440×900`、`860×900`、`390×844` 三档视口检查 A/B/D，页面宽度均等于视口宽度，无横向溢出；桌面三案均完成截图。
- 当轮 `npm --prefix MultiMix-Frontend run docs:check` 通过，未改动正式产品实现；后续已决定无产物时不展示右侧，本探索不再等待生产实施。
