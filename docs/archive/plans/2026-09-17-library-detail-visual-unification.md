# 资源详情弹窗视觉统一实施计划

> Status: archived
> Owner: frontend
> Last verified: 2026-09-17

## 背景与根因

资源库内容页已经统一，但图片、视频、文案和资产详情仍沿用“内容连续堆叠 + 所有操作同权平铺”的旧结构。标题上方只有一行混合元信息，正文滚动与整个弹窗滚动没有分工，底部 5–7 个按钮视觉权重相同；用户难以快速判断资源类型、当前状态和下一步主操作。

本轮只优化桌面端详情弹窗的信息层级、内容容器和操作优先级，不改变数据字段、业务能力、删除确认、素材解析、下载、加入项目或用于创作的行为。

## 已锁定设计

- 详情弹窗使用统一三段结构：固定头部、独立滚动内容区、固定底部操作区。
- 头部明确展示资源类型、状态、标题和更新时间/引用次数；关闭按钮保持右上角。
- 图片、视频、文案和资产共享相同标题层级与内容块间距；媒体比例和各自业务内容不被抹平。
- 每类详情只保留一个深色主操作；常用次级操作直接展示，重新解析、下载、来源、导出和删除等低频操作收进“更多”菜单。
- 删除继续使用危险色并保留二次确认；禁用态和键盘焦点必须清晰。
- 桌面弹窗宽度适度增加，正文只在内容区滚动，底部操作不随长内容消失。

## 风险与取舍

- 低频菜单会减少一眼可见的按钮数量，但所有能力仍保留，并通过原生可聚焦控件保证键盘可达。
- 固定底部操作区会占用少量垂直空间，因此正文必须由独立滚动区承载，避免整个弹窗越界。
- 视频工程的“打开剪辑器”比“用于创作”更接近主任务；仅在工程已完成时作为主操作，其他视频仍以“用于创作”为主。
- 本轮不修改手机端和 `<= 1180px` 响应式策略。
