# 产物异步作用域与提示样式整改

> Status: current
> Owner: frontend
> Last verified: 2026-09-29

## 背景与根因

用户批准修复最近只读审查确认的三个问题：P1 同一项目保存文稿 A 后切换文稿 B，A 晚到响应退出 B 编辑、丢弃 B 未保存文字并伪显示已保存；P2 历史预览 v1 的晚到响应覆盖最后选择的 v2；P2 冲突读取提示依赖未加载的 Tailwind utility，实际按钮高 27px、圆角 0、提示无留白。

根因分别是异步局部状态没有绑定产物/编辑会话，历史预览没有最后请求校验，样式与工作台原生 CSS 体系不一致。前轮恢复互斥不回退，跨项目切换未复现的串扰不当作确认问题。

## 具体改法

1. 文稿保存的同步占用按产物绑定，当前 busy 状态按请求所属视图推导；视图身份包括项目、产物、内容基准和 token，身份往返不能复活旧编辑会话。成功结果可通过请求时的回填回调更新原产物，但不设置新产物的编辑正文/已保存/退出状态。捕获原请求基准并校验响应资产；父容器仅基准仍匹配时合并。账号变更或卸载后不回填。失败、结构确认、finally 同样只影响原会话，旧 finally 不清除新请求状态。
2. 历史预览按递增请求及视图身份接受最后结果；新请求清理旧内容，旧成功/失败/finally 不覆盖新选择。切换、卸载及退出预览使请求失效。预览对象同时保存版本标签与快照，明确显示“历史版本预览 · v2”，不改变当前产物或发起写入。
3. 冲突提示使用本工作台专用 CSS：自然高度、flex 换行、14px 文本、12px/20px 留白；读取按钮最小高 40px、细边框、圆角、禁用和键盘焦点样式，窄屏无溢出。保留与头部同一网格行，避免遮挡主图。不全局引入 Tailwind，不改播放器视觉合同。

## 风险与取舍

- 不以禁止切换产物代替状态隔离；不新增跨项目草稿自动持久化。本轮保证晚到响应不干扰当前编辑，正常切换时原有草稿行为不扩大。
- 捕获成功回填更新原产物，避免只丢弃响应导致服务端已保存、原产物缓存仍旧；同时基准与认证检查避免覆盖期间更新。
- A→B→A 或同一产物内容基准变化后，旧保存不回填当前新编辑会话，以免父容器刷新再次退出编辑；服务端保存仍有效，随后主动读取可同步。当前已切到不同产物时，仍按原基准回填原产物缓存。
- 不改后端 schema、文本语义、恢复接口、主库、生产或独立剪辑器，不调用真实付费供应商。
- 保留前轮未提交改动；未获提交/推送授权。
