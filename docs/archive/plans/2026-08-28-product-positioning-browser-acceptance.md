# MultiMix 产品定位浏览器验收计划

> Status: qa
> Owner: frontend
> Last verified: 2026-08-28

## 背景与验收目标

产品定位与首屏文案已统一为“素材驱动的 AI 短视频创作工作台”，但现有验证以静态文案测试为主，尚未用真实浏览器确认登录页、新建页、推荐任务和能力状态在桌面端与移动端的可见性、层级和交互。

本轮先建立隔离的浏览器验收闭环：验证用户能从登录页进入新建页，看到统一定位、三类推荐任务和“优先使用用户素材、内容有依据、结果可修改”的能力承诺；同时检查控制台错误、横向溢出和关键按钮可用性。若发现缺陷，只做与本轮定位文案直接相关的最小修正。

## 涉及文件与关键位置

- `app/multimix-app.tsx`：登录/注册页标题与简短定位文案。
- `app/assets/components/conversation-start.tsx`：新建页主标题、副标题、推荐任务和素材说明。
- `app/assets/components/materials-ready-strip.tsx`：素材就绪状态与信任承诺。
- `app/assets/components/ai-background-status.tsx`：AI 能力状态文案。
- `app/assets/lib/asset-workspace-empty-data.ts`：新建页空状态信息。
- `app/assets/lib/runtime-write-capabilities.ts`：能力状态提示。
- `e2e/product-positioning.spec.ts`：新增的定位浏览器验收用例与截图证据。
- `scripts/run-product-positioning-e2e.mjs`：隔离启动、端口检查、临时数据库和进程清理。
- `package.json`：增加本轮 E2E 的显式运行入口。

## 具体做法

1. 用独立后端端口 `8298`、前端端口 `3220` 启动测试环境，不占用开发者的 `3117/3200`。
2. 使用系统临时目录中的一次性 SQLite 和素材目录，先通过后端官方 `app.database_cli bootstrap` 建表，再启动本地认证服务；关闭 Supabase 与外部生成服务，结束时无论成功或失败都清理进程、Next 临时构建目录和测试数据。
3. 浏览器先验证登录页，再注册一次性本地账号进入工作台，验证新建页、推荐任务、附件提示和能力状态。
4. 在 1440×960 桌面视口完成正式验收并截图，检查统一定位文案是否完整可见、是否横向溢出、主要交互是否可用，并收集浏览器控制台错误；额外保留 390×844 探索截图，但不把移动端作为当前发布契约。
5. 若发现问题，先把证据和修订范围补回本计划，再修改最小文件并复测；不改变导航结构、数据库契约、API、视频引擎，也不删除文案/图片独立能力。

## 风险与取舍

- 本轮使用本地认证和隔离数据库，只验证首屏定位与进入工作台的真实浏览器体验，不验证生产 Supabase 登录、外部模型生成或完整视频渲染。
- 当前 UI 权威规格 `docs/specs/ui/agentic-workbench-design.md` 明确锁定 1280+ 桌面端，移动端/响应式尚不在当前范围；390×844 截图中推荐任务右列被裁切，作为后续响应式设计输入记录，不在本轮修改。
- 截图用于人工验收证据，不直接建立像素级基线，避免把当前机器的字体渲染差异固化为产品契约。
- 工作区已有与资产生成任务相关的未提交改动，本轮不读取其意图、不修改、不暂存、不提交。

## 验证方式

- `npm run test:e2e:product-positioning`
- Playwright 断言：登录页、新建页、三类推荐任务、素材说明、能力状态、控制台错误与横向溢出。
- 人工查看桌面端和移动端截图。
- 若发生代码修正，再运行相关 Vitest、`npm run typecheck`、`npm run docs:check` 和 `npm run check:agents`。

## 首轮执行记录

- 2026-08-28 首轮真实浏览器运行在注册后失败，截图和后端日志确认原因是全新 SQLite 尚未执行 schema bootstrap，`users` 表不存在；这属于验收运行器初始化缺口，不是定位页面产品缺陷。
- 运行器补充官方数据库 bootstrap，并把单用例超时提高到 90 秒，避免把注册后的页面加载时间与 Playwright 默认 30 秒总超时混为一谈。
- 第二轮 E2E 通过（1/1）：登录、注册、新建页、四类推荐任务、素材说明、上传/发送能力以及文案库/图片库/视频库保留均验证通过；无浏览器控制台错误或未捕获页面错误。
- 桌面截图人工检查通过。移动截图仅作探索，发现的任务卡裁切与当前“1280+ 桌面”范围一致，未改动 `app/assets`，也未与正在进行的资产生成任务发生写入冲突。
- 第二轮结束后确认临时 SQLite、`-wal/-shm`、素材目录、8298/3220 监听进程和 Next 临时目录均已清理；截图与日志保留在 `test-results/product-positioning/20260828-7052-r2/`。

## 执行方式

按用户要求在当前任务中逐步执行，不启用 Subagent，不自动提交或推送。
