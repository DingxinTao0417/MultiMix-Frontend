# 当前轮参考图绑定修复

> Status: archived
> Owner: frontend
> Last verified: 2026-09-07

## 背景与根因

生产会话的“加入项目”和素材详情“用于创作”都不会将素材作为当前会话下一条消息的显式参考图，导致“只重做 F04”被错误路由为编导稿。后端已支持版本化 `reference_context_selection_version=v1`，根因是生产前端缺少该选择入口及可见状态。

## 改法

- 在项目资源的 active source 提供非付费“用于本轮”。
- 仅在当前会话保存单一参考图，下一条消息才携带该 ID。
- 输入框展示和允许移除本轮参考；刷新时只恢复带版本化显式证据的选择。

## 风险与验证

不从项目或历史产物猜测参考图，不开放文生图或绕过确认。运行单元测试、类型检查、文档检查；发布后验证选图后只出现图片确认卡，并且没有编导稿、视频工程或 Modal 调用，确认前零费用。
