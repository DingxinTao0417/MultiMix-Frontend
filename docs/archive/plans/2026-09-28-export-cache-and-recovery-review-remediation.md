# 导出缓存身份、下载状态与迟到恢复整改

> Status: completed
> Owner: frontend
> Last verified: 2026-09-28

## 背景与根因

用户确认修复本轮审查问题：工作台缓存只按导出类型保存、只在切换资产时清理，同一工程的新版本可能下载旧 Blob；独立编辑器 ExportButton 的缓存分支绕过 EditorView，导致成功下载仍保留另一版失败提示。原始版后台恢复与用户主动品牌版操作共用界面状态，迟到结果缺乏当前请求身份约束，需先复现再修复。

- `app/assets/components/product-workspace.tsx:220–265、603–628、917–1015、1092–1248`：缓存身份、后台恢复及下载。

- `app/assets/__tests__/agent-ui-copy.test.ts:1350`、`asset-generation-job-ui.test.tsx:49`：按当前单栏空态与可折叠失败进度规则校准测试，不更改产品视觉方向。

## 具体改法与边界

1. 工作台用资产 ID、内容 hash、版本与服务端 `video_project_quality_approval.fingerprint` 组成缓存内容身份；内容身份变化清除所有导出类型的文件、任务与报告。发布文件引用/报告本身不参与身份，避免成功刷新误失效；历史缺少批准指纹时沿用内容 hash/版本身份，不伪造后端指纹。
2. 独立编辑器缓存下载完成后通知唯一状态持有者更新当前类型、完成状态与错误。缓存状态变更不触发渲染或上传。真实 ExportButton 交互进入测试，移除掩盖缓存分支的测试替身。
3. 工作台与独立编辑器后台原始版恢复绑定启动时的内容/请求身份；用户主动操作使旧恢复不能写当前状态。工程变更后旧异步下载与任务结果不能填回新内容缓存。工程详情刷新也需在应用产物/错误前复核内容身份，导出触发的刷新额外复核请求身份。对 AbortSignal 不被测试替身遵守的情况仍按身份丢弃结果。保留同一任务的显式重试规则。
4. 只校准有权威规则依据的旧断言：无产物时右栏隐藏；失败摘要/重试在收起详情后仍可见，不要求详情永久不存在。

不改后端协议/质量门、数据、依赖、生产配置、播放器外壳或任何截图基线。vendor 仅改 ExportButton 的窄交互合同，不动渲染引擎。

## 风险与取舍

- 不以禁用缓存代替身份修复；同内容的重复下载仍复用已验证文件。
- 对后台恢复与主动操作用本地请求序号隔离，不改变服务端任务事实。遗留恢复只读结果不能覆盖较新的用户操作。
- 内容 hash/版本改变可能保守失效，优先避免交付旧片。缺少现代批准字段的历史项目仍依赖服务端已有版本合同。
- 测试层级 L2，接口/引擎隔离、付费调用零。组件验证不代表真实浏览器编码/上传或生产全链路。

## 验证方式

- 先复现 v1 下载后同资产 v2、同版本内容 hash 或批准指纹改变仍下载旧 Blob；修复后重新查询当前任务/文件。原内容重复下载不新增任务。
- 原始版缓存成功 + 品牌版失败 + 下载原始版：文件下载，旧失败提示清除，不重渲染、不重上传。
- 原始版查询延迟，品牌版已成功/失败/进行中后旧查询返回：当前状态不被覆盖；旧内容任务等待/下载晚到不写回。
- 保留已修的品牌版失败停止与显式 retry 案例；补真实按钮交互。
- 相关 Vitest、typecheck、lint、test:fast、build、check:agents、diff 检查。全量遗留失败按当前设计核对，不能仅删除断言换取通过。
