# 首页按制作起点组织入口

> Status: archived
> Owner: frontend
> Last verified: 2026-09-29

## 背景与根因

用户已确认首页入口使用“从想法开始 / 用素材创作 / 修改现有视频”，并为每项提供一句说明。现有新建页在 `app/assets/components/conversation-start.tsx:40-69,478-502` 展示“讲清楚、推广产品、讲个故事、优化已有视频”四张内容目标卡，第一组与下方“只有一个想法/一张图片/一段原视频”示例所表达的开始方式不一致；其中“优化已有视频”又是操作入口而非内容目标。`app/globals.css:1430-1434` 和当前原型 `docs/specs/ui/prototypes/current/screens/start.html:180,389-408` 固定四列。权威交互说明 `docs/MULTIMIX_WORKSPACE_DESIGN.md:203-215` 仍描述四张卡。

入口应让非专业用户先判断如何开始制作，同时保留自由输入，不把页面卡片变成后端视频类型、模型选项或能力承诺。新片可以从想法或素材开始；“参考视频另做一条”属于用素材创作，“保留原片后修改”属于修改现有视频。人物口型、高保真复刻、活动大屏等具体需求可以提出，但首页不承诺当前均能稳定交付。

## 本轮具体改法

1. 在 `app/assets/components/conversation-start.tsx` 将四张卡收敛为三张：
   - **从想法开始** — “说出目标，一起确定内容和画面。”点击后只填入可编辑的起始需求，不声称用户已有素材。
   - **用素材创作** — “上传照片、人物、资料或参考片，制作新作品。”点击后先询问用户将提供哪些素材与参考用途，不假设附件已上传。
   - **修改现有视频** — “上传原片，说明要保留和调整的部分。”点击后先确认原片和保留/修改范围，不假设原声或主体必然保留。
2. 将该组标题改为“选择一个开始方式”，将下方示例标题改为“试试这样描述”，说明文字改成“入口和示例只会填入一段可编辑的需求……”。保留自由输入框、被动能力提示、下方三个具体示例、点击仅填词而不自动提交的交互。新入口使用稳定且语义准确的推荐事件 key；不把旧内容目标 key 改名后继续复用。
3. `app/globals.css` 和当前原型 `docs/specs/ui/prototypes/current/screens/start.html` 的桌面布局改三列；窄屏两列时第三张跨整行，移动端改为单列，避免三卡在旧四列布局中留下空位。沿用现有图片与遮罩，不新生成媒体。当前原型同步入口文案和预填词。
4. 更新 `docs/MULTIMIX_WORKSPACE_DESIGN.md` 与 `docs/specs/ui/agentic-workbench-design.md` 的首页入口说明；三类产品/知识/案例结果继续作为首发验证场景，不变成新的首页必选分类。更新 `app/assets/__tests__/conversation-start-primary-tasks.test.tsx`、`app/assets/__tests__/product-analytics-events.test.tsx`、`app/assets/__tests__/agent-ui-copy.test.ts` 和 `scripts/check-conversation-entry.mjs` 中相关断言，避免页面与检查口径冲突。

## 风险与取舍

- “从想法开始”和“用素材创作”是建议起点，不是互斥流程：用户可以在任意阶段补充素材，选择卡片不锁定五层规划。
- “参考片”只表示用户可以提交参考并说明用途，不等于承诺任意视频高保真复刻。
- 推荐事件 key 从内容目标切到制作起点后，前后两段数据口径不同；保持事件名不变，使用新 key 避免历史数据被误合并。
- `app/globals.css` 已有其他未提交改动，本轮仅修改入口卡片相关规则，不覆盖其他人的布局调整。
