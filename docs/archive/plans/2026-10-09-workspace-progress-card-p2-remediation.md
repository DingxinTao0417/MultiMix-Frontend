# 工作台进度卡与资料文档 P2 整改

> Status: archived
> Owner: frontend
> Last verified: 2026-10-09

## 背景与根因

2026-10-09 工作台审查确认三处 P2：`app/assets/components/video-progress-card.tsx:94-126` 把供应商费用记录及“尚无已留账的调用”放进默认摘要，破坏紧凑状态卡的一句说明原则；`app/globals.css:10058-10070` 的失败步骤入口为 11px，低于当前 12px 元信息下限；`docs/API.md:1304` 仍宣称项目资料抽屉可永久删除，与当前 UI 和引用保护规则不符。根因分别是费用数据展示与任务状态未分层、局部样式未遵守统一字号、接口说明未随抽屉行为更新。

## 改法与范围

1. `app/assets/components/video-progress-card.tsx`：摘要保留状态、必要说明、失败原因与动作；已有图生视频、配音和渲染费用说明移至同一“进度详情”展开区域，保持原有金额/次数/未知覆盖口径。零记录时改用用户可理解的“暂无可显示的费用记录，不代表没有成本”，不宣称零费用。保持按钮的 `aria-expanded` / `aria-controls` 指向完整详情。
   `app/assets/__tests__/video-progress-card.test.tsx` 与 `app/assets/__tests__/video-progress-integration.test.tsx` 同步验证组件及对话接线；后者原断言要求费用默认出现，须改为默认收起且展开可查，不删除费用数值断言。
2. `app/globals.css`：进度详情入口字号调至 12px，保持现有颜色、间距与触达高度；费用说明作为次级信息排版，不加独立卡片。
3. `docs/API.md`：项目资料抽屉动作改为打开、移出、可用历史资料重新加入；明确不在抽屉永久删除有项目关系或历史引用的源文件。

不改后端费用计算、任务状态机、播放器、资料删除接口或生产配置。

## 风险与取舍

- 费用不再默认占据摘要，但展开后仍完整可查；不把“未知”误写成零。
- `aria-controls` 从关键进展列表扩展为详情容器，现有列表语义与展开/收起行为必须保持。
- 失败原因与重试动作继续默认可见，不与费用一起折叠。
