# 编辑内容与导出恢复身份整改

> Status: archived
> Owner: frontend
> Last verified: 2026-09-28

## 背景与根因

本轮只读审查确认：独立编辑器的已验证 Blob 仅按导出类型缓存，按钮绕过状态持有者与当前编辑内容校验；保存清理缓存但未使旧恢复请求失效，旧任务可再次填回缓存。品牌版 current 查询基于服务端已保存工程，不能替代当前未保存内容的检查。工作台 bridge 对相同资产/导出类型的旧窗口消息缺少来源与请求约束，先复现再修复。

## 涉及文件与位置

- `app/editor/EditorView.tsx:114、247、334、601–976`：内容身份、缓存失效、导出检查、保存/BGM、恢复生命周期；`handleEmbeddedExport`：桥接导出响应。
- `editor-engine/vendor/ExportButton.tsx:34–79`：统一把选择交回状态持有者，下载函数保持唯一实现。
- `app/editor/__tests__/standalone-export.test.tsx`：真实按钮、引擎内容变化、保存/BGM、异步回填与重试测试。
- `app/assets/components/product-workspace.tsx:680–698、754–925` 与 `app/assets/__tests__/product-workspace-video-actions.test.tsx`：旧窗口及请求身份复现/保护。
- `app/editor/__tests__/editor-layout.test.ts`、`docs/API.md`：窄 bridge/按钮契约同步。

## 具体改法

1. 先把两项只读诊断转为修复后行为断言，加入两种导出类型及工作台旧窗口复现。
2. 导出选择全部进入 EditorView。已验证文件记录实际编辑内容身份及导出类型/品牌规范；点击时核对实时序列化内容；内容未保存时不读旧服务端任务，改走既有保存、预检、合成、上传和验证流程。订阅实际内容管理器（scenes/project/media），不订阅播放或选择；序列化实际 tracks/media/settings/metadata 比较，不把纯 MP4 发布字段纳入本地内容身份。撤销也按实际内容比较，未变化的重复下载仍复用缓存。
3. 保存/BGM 开始及实际编辑内容变化使旧导出请求失效；后台恢复、主动 current/retry/下载、渲染后上传和状态回写均绑定请求与内容身份。后台恢复只针对已保存内容，授权回调变化也不能恢复未保存内容的旧片。主动导出期间禁用手动保存并拒绝新增配乐变更；旧渲染无法中途停止时等待结束且禁止上传旧结果，不伪装成功，也不启动第二个并发渲染。
4. bridge 风险已复现，工作台只接受当前 iframe 的消息；导出命令附唯一请求 ID，回复回显并匹配当前请求与工程身份。工程更新及重建使旧请求失效；现有 previewChannel/flush 协议保留。

## 风险与取舍

- 本地内容身份用于缓存/请求隔离，不替代服务端批准指纹、文件质量门、幂等或确认门。
- 不简单禁用所有缓存，不引入轮询内容、付费调用、后端协议迁移或新的视觉方向。
- vendor 只改导出按钮窄合同；不改序列化器、素材链路、渲染引擎或播放器外壳。
- 不提交/合并/推送，保留两仓既有脏文件。无后端/生产/配置/数据变更。

## 验证方式

L2 离线相关回归，外部付费调用为零，不启动服务或数据库。

- 原始/品牌缓存后改时间轴、修改并撤销、未变内容重复下载：只允许身份相同的缓存；新内容保存后走既有质量门，不能下载旧片。
- 保存/BGM 前发起恢复，保存/更新完成后旧查询/文件返回：不得填回、报旧错或显示旧完成；新的导出正常可用。
- 主动品牌任务查询/下载中修改内容，旧结果不得回写；合成中修改不得上传旧候选；明确重试仍复用同内容任务。
- iframe 旧窗口、旧请求、换版后的消息拒绝，当前窗口/请求成功正常处理。
- 定向 Vitest、typecheck、lint、test:fast、build、check:agents、diff 检查；归档并释放占用。组件测试不代表真实浏览器编码上传或生产端到端。
