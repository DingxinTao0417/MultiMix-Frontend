# 对话空展示区：阶段知识卡重做

> Status: archived
> Owner: frontend
> Last verified: 2026-09-23

## 背景与根因

已提交的对话空展示区复用了新建项目的抽象分镜画布和三步路径，只替换了标题、一步高亮和提示文案。用户在真实截图中无法从视觉上区分“刚创建项目”和“对话正在推进但尚无产物”，因此没有真正承担教程/扫盲作用。

## 目标与范围

- 只重做已有对话、`selectedProduct` 为空时的右侧展示区；新建项目的“创作起点”完全保持不变。
- 将复用空态替换为独立的阶段知识卡：阶段编号、一个解释性标题、三项固定知识点和一句结果说明。
- 继续只消费确定性阶段（普通澄清、显式资料、结构化待确认计划），不展示用户文本、资料统计、进度、按钮或第二输入入口。
- 不改后端 API、对话编排、确认卡、视频预览或产物选择逻辑。

用户复核知识卡后确认：待确认阶段不应再次解释左侧卡片已经承载的“要确认什么”。该阶段改为解释“确认不是锁死”，只展示生成后仍可进行的三类修改和下一步结果；普通澄清、资料阶段继续承担流程教程。

用户第三次复核确认：内容方向已经正确，但居中的内层卡片造成“卡片套卡片”和大面积上下留白。对话教程需要改为铺满右侧主体的编辑式教程画布，去掉内层边框、圆角、阴影和独立标题栏，以大号阶段编号、左右分栏知识和底部横向结果流程使用空间。

## 涉及文件与关键行

- `app/assets/lib/conversation-empty-display-tutorial.ts`：为每个确定性阶段补齐标题、说明和三项固定知识点，集中维护内容边界。
- `app/assets/components/product-workspace.tsx:164`：新建会话继续渲染原有画布；对话变体改为知识卡语义结构，不复用分镜画布与三步路径。
- `app/globals.css:4242`：新增对话知识卡限定样式与窄屏布局，只覆盖 `conversation-tutorial` 变体。
- `docs/MULTIMIX_WORKSPACE_DESIGN.md:57`：更新已确认的对话空展示区视觉/信息规则。
- `app/assets/__tests__/display-area-cases.test.tsx`：覆盖三种阶段的标题、要点、无交互和新建变体不回归。

## 具体改法

1. 每种阶段提供“阶段编号 / 标题 / 说明 / 三项知识点 / 结果提示”的固定内容。待确认阶段使用“确认不是锁死”，以三个轻量标签说明“改文案 / 换镜头 / 调节奏”，并说明下一步会得到可继续编辑的视频工程；其余两种阶段使用对应的通用创作知识，不从会话正文取值。
2. 对话变体渲染铺满展示主体的编辑式教程画布，使用大号 `01 / 03` 或 `02 / 03` 作为视觉锚点：左侧承载标题与解释，右侧纵向承载知识点或可修改项，底部横向连接当前动作与下一产物。画布自身不使用边框、圆角、阴影或卡片背景。
3. 新建变体仍使用原有抽象画布、三步路径与引导语，确保两种场景在视觉结构上明确不同。
4. 运行相关 Vitest、类型检查和文档检查；使用一次性 SQLite 在 8495/3495 打开真实待确认对话截图，结束后清理数据库与进程。

## 风险与取舍

- 知识点必须是流程常识，而不是“系统已理解用户需求”的假结论；不能出现用户目标、素材名称或生成状态。
- 不把确认按钮移入右侧，避免与左侧对话确认卡形成双入口。
- 该改动只纠正对话空态，不触碰已确认的新建起点或视频播放器契约。

## 验证方式

1. Vitest：验证每种阶段的教程画布标题、三项要点、无内层卡片、无按钮/无聊天回显和新建变体。
2. 运行 `npm run typecheck`、`npm run docs:check`。
3. 使用 `~/Desktop/multimix-test-results/e2e-runtime/conversation-tutorial-knowledge-card-20260923/runtime.sqlite3` 进行隔离页面截图，绝不连接 Supabase 或占用 3117/3200；截图后删除临时目录并停止 8495/3495 进程。

## 实施结果

- 对话空展示区已从复用的新建分镜占位，改为铺满右侧主体的编辑式教程画布；画布使用大号 `01 / 03` 或 `02 / 03`、左右分栏知识和底部横向结果流程，不再形成内层卡片。
- 待确认阶段显示“确认不是锁死”，仅说明生成后仍可改文案、换镜头和调节奏，并预告下一步得到可继续编辑的视频工程；其余阶段同样只提供固定流程知识，不读取聊天正文。
- 新建项目继续使用原有创作起点画布和三步路径，视觉结构未改。
- 2026-09-23 通过相关 Vitest 109 项、`npm run typecheck`、`npm run docs:check`，并在隔离的真实待确认对话中完成 `1440×900` 浏览器截图；最终画面以满版左右分栏显示“确认不是锁死”“改文案 / 换镜头 / 调节奏”和“确认方案 → 生成可编辑视频工程”。临时 SQLite、8495/3495 进程和构建目录均已清理。
