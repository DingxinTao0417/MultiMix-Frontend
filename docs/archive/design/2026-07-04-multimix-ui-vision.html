UI 视觉方案 · 2026.07

MultiMix — 现在应该跑通什么，UI 怎么做

基于商业计划书 multiMix 定位版，结合现有代码现状，给出优先体验清单 + 新视觉方案。

Part 1 · 优先跑通的体验

0–6 个月 MVP 验证闭环：三层递进

商业计划书最核心的验证目标是：「高客单本地商家，用真实素材直接生成可发布内容，并愿意持续付费」。要证明这件事，有且只有以下三层体验必须真正跑通。

🔴 第一优先 · 必须跑通

对话 → 确认 → 生成文案/视频方案

  • 商家说「帮我做一条门窗安装的小红书视频」，AI 能结构化意图并给出确认卡
  • 确认卡里要有：目标平台、素材引用、大致方向，用户一键确认就能执行
  • 生成后右侧能立刻看到文案或视频脚本，不是空白等待
  • 支持「改短一点」「换个开头」这类最高频修改指令立即生效
验证指标：首版可用率 > 60%，不需要超过 2 轮就能发
🔴 第一优先 · 必须跑通

素材上传 → 理解 → 在生成中被引用

  • 商家能上传门店图/施工图，AI 能识别出「这是一个家装案例，有客厅翻新」
  • 对话里能引用「用我第 3 张图做封面」，生成结果中真实体现
  • 素材库里看到图片是否已被理解（已解析 / 待处理 标签）
  • 这是核心差异化：不是通用生成，而是懂你的原材料
验证指标：每次对话平均引用自有素材 > 1 个
🟡 第二优先 · 跑通后再做

外部情报拆解 → 用于选题

  • AI 能引用「最近家装类 top 视频的开头结构」给建议
  • 选题建议页面：今天适合发什么，背后有依据
  • 不需要用户自己找，直接在对话里作为上下文
  • 这是「情报拆解」步骤——先把前两步跑通，再加这层
验证指标：选题采纳率 > 40%
🟡 第二优先 · 跑通后再做

历史内容复用 · 资产沉淀感

  • 用户发完一条内容后，这次素材使用、修改路径会保留
  • 下次再说「像上次那个风格」，AI 能调用历史
  • 资产库要让用户感知到「东西越用越多，不是用一次扔一次」
  • 这是续费意愿和防流失的关键——做完 MVP 再加
验证指标：素材复用率 > 30% / 月
🟣 第三优先 · MVP 后规划

视频编排 · MG 动效 · 数字人

  • 视频脚本 → 完整 timeline 自动拼装
  • MG 补位场景（缺素材时用 MG 动效补帧）
  • 数字人口播嵌入对话工作台
  • 后端 video_studio + remotion 模块已在，但上游体验不稳时先不暴露给用户
验证指标：6 个月后外贸试点
🟣 第三优先 · MVP 后规划

订阅付费 · 用量仪表盘

  • 生成次数、素材处理量、已用空间的可视化
  • 套餐对比页面和升级入口
  • 真正的付费按钮和 Webhook 通知
  • 先在 1-2 个种子用户里验证 playbook，再做收费系统
验证指标：月付费用户 > 10 家

Part 2 · 现有 UI 评估

骨架正确，但缺乏「内容生产工具」的气质

当前前端代码实现了正确的架构（对话 + 产物双栏、adapter 层、mock 模式），但视觉语言偏通用 SaaS，不能让一个本地商家感受到「这就是为我做的」。

需要改进的问题

  • 配色走的是浅色/中性调，没有明确品牌辨识度，和竞品没有视觉差异
  • 对话区和产物区视觉权重几乎相等，用户不清楚哪里是「主区域」
  • 确认卡（Agent 生成前的确认步骤）太平，不够有存在感——这是产品最核心的交互，应该醒目
  • 素材卡片没有「理解状态」的反馈：哪些图已分析，哪些待处理，用户看不出来
  • 空状态（新对话、空库）缺乏引导感，不知道从哪里开始
  • 字体层次不够，标题/正文/辅助信息视觉差异太小，密度偏高
  • 没有体现「内容生产工作台」的专业感，看起来更像 ChatGPT wrapper

做得对的部分，保留

  • 对话 + 产物双栏布局是对的，不要改成单栏
  • 拖拽分栏宽度的交互很实用，保留
  • Adapter 层与 mock 分离，不影响 UI 迭代，架构正确
  • 产物卡在对话流里内嵌的方式是对的——产物不应该和消息分离
  • 侧边栏的对话列表 + 库切换，信息架构基本合理
  • 消息流中的建议词（suggestion chips）这个组件形态好，继续用
  • 右侧抽屉做详情的思路对，不要用 modal

Part 3 · 视觉方案

深色工作台 × 橙色主视觉 × 内容优先

核心设计决策：深色背景让内容（文案、图片、视频帧）自然成为视觉焦点； 橙色 #FF5C00 作为唯一品牌色，只用于核心动作（确认生成、品牌 logo、状态高亮），不滥用； 布局让 产物区比对话区更宽，反映「结果导向」而非「聊天导向」。

设计原则总结

四条不能打破的原则

🎯
产物比对话更重要

产物区（右侧）默认宽于对话区，传递「我给你结果」而非「我们在聊天」的信号。空状态时用视频脚本卡片占位，不要空白。

🔶
橙色只用于核心动作

确认生成按钮、品牌 Logo、待确认状态徽章——这三处用橙色。其余全部用 #8A8A8A 灰色，不稀释品牌色权重。

🗃️
素材状态必须可见

每张图片卡片都有「已解析 / 待处理」状态和「被引用 N 次」计数。用户感知到素材在被系统理解和使用，是资产沉淀感的来源。

✅
确认卡是最重要的交互

Agent 在执行生成前的确认卡，是产品核心差异化的视觉体现。要比聊天气泡更大、更有存在感，背景色区分，不能埋进消息流里。
